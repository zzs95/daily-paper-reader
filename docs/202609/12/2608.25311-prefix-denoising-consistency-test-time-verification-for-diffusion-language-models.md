## 1. 核心问题与研究动机

- **背景**：扩散语言模型（DLM，如 LLaDA、Dream）通过迭代去噪生成输出，不遵循从左到右的顺序，近期在语言与推理任务上已能与自回归（AR）模型竞争，甚至部分任务反超。
- **核心痛点**：为获得强 pass@1 精度，SOTA DLM 通常在**低温度**下解码，这导致重复采样得到的去噪轨迹高度相似、答案近乎一致。因此 AR 领域经典的 **self-consistency（多路径采样 + 多数投票）** 难以直接迁移到 DLM——样本间的一致性可能只是"同一条轨迹的复制"，投票会高估可靠性而非提供独立检验。
- **已有工作的局限**：TIF（Temporal Information Feature，Wang et al., 2026a）利用单次去噪过程中间步骤的时序信息投票，虽有效，但**只复用了同一条轨迹**，无法在轨迹锁死到错误推理路径后"另起分支"。
- **本文目标**：为 DLM 设计一种**测试时自验证（test-time self-verification）** 原语，能够真正产生结构化的替代轨迹，从而修正初始生成中的错误。

## 2. 方法论：Prefix-Denoising Consistency (PDC)

### 2.1 核心思想

- 给定一个已完成的初始输出 $y$，**保留其精确前缀**，将剩余后缀位置重新加掩码（remask），在**同一输出窗口长度 $L$ 内**重新去噪，得到替代候选；对多个保留率下的重生成答案做**多数投票**。
- 关键前提（经验观察）：**正确轨迹比重错误轨迹更"可复现"**。因此，若重生成结果一致，更可能是真正可靠的答案。

### 2.2 技术细节与算法流程

1. 标准 DLM 推理：给定提示 $x$、输出长度 $L$、去噪步数 $T$，输出 $y = \mathrm{DLM}(x; L, T)$，长度 $\ell_y = |y|$，初始答案 $a^{(0)} = \mathrm{Extract}(y)$。
2. 对每个保留率 $\rho \in \mathcal{R} = \{0.1, 0.5, 0.9\}$：
   - 保留前缀长度 $L^{\text{prefix}}_\rho = \max(1, \lfloor \rho \ell_y \rfloor)$（$\ell_y = 0$ 时为 0）；
   - 需重生成的后缀长度 $L_\rho = L - L^{\text{prefix}}_\rho$，对应去噪步数 $T_\rho = L_\rho$；
   - 构造输入 $z^{(0)}_\rho = [x,\ y_{1:L^{\text{prefix}}_\rho},\ \underbrace{[\text{MASK}], \dots, [\text{MASK}]}_{L_\rho}]$；
   - 得到 $y^{(\rho)} = \mathrm{DLM}(x, y_{1:L^{\text{prefix}}_\rho}; L_\rho, T_\rho)$，抽取 $a^{(\rho)} = \mathrm{Extract}(y^{(\rho)})$。
3. 投票集合 $B = \{a^{(\rho)} : \rho \in \mathcal{R}, a^{(\rho)} \neq \varnothing\}$；若 $B = \varnothing$ 返回 no-vote，否则 $\hat a = \mathrm{Maj}(B)$，平票按固定顺序 $0.1 \to 0.5 \to 0.9$ 打破。
4. **初始答案 $a^{(0)}$ 被排除在投票之外**，以隔离前缀条件重生成本身的效应。

**三个保留率的语义**：$\rho=0.1$ 弱条件，允许大部分推理路径改变；$\rho=0.9$ 强条件，仅扰动尾部；$\rho=0.5$ 居中。

### 2.3 诊断指标与理论分析

- **可复现率**（复现率的定义）：
  - 正确答案保留率 $R^+_\rho = \Pr[a^{(\rho)} = a^\star \mid a^{(0)} = a^\star]$
  - 同错答案持续率 $R^-_\rho = \Pr[a^{(\rho)} = a^{(0)} \mid a^{(0)} \neq \varnothing, a^{(0)} \neq a^\star]$
  - **观察 2.1**：跨设置普遍有 $R^+_\rho \geq R^-_\rho$（附录 Table 4 中绝大多数行成立，少数 CSQA/SQA/SVAMP 行为负）。
- **定理 2.2（复现差距的收益）**：设二值答案空间 $\{a^\star, b\}$、无空答案、给定 $a^{(0)}$ 时三次重生成条件独立，$\pi = \Pr[a^{(0)} = a^\star]$，$V_3(p) = p_1p_2+p_1p_3+p_2p_3-2p_1p_2p_3$（等概率时 $V_3(p)=3p^2-2p^3$），则
  $$\mathrm{Acc}(\mathrm{PDC}) = \pi V_3(R^+) + (1-\pi)\left[1 - V_3(R^-)\right]$$
  改进当且仅当 $\pi < \frac{1 - V_3(R^-)}{2 - V_3(R^-) - V_3(R^+)}$；当 $\pi = 1/2$ 时，$\mathrm{Acc}(\mathrm{PDC}) - \mathrm{Acc}(\mathrm{INIT}) = \frac{1}{2}[V_3(R^+) - V_3(R^-)]$。
- **直觉解读**：改进量 = "被纠正的错误初始答案" − "被破坏的正确初始答案"；由于 $V_3$ 对每个坐标单调递增，$R^+_{\rho_j} \geq R^-_{\rho_j}$（至少一个严格）即为改进的充分条件。

- **诊断信号成立**：前缀条件下重生成时，初始正确答案的保留率 $R^+$ 显著高于同错答案持续率 $R^-$（GSM8K 上 Dream-7B 的 $\Delta$ 可达 15–16 个百分点；LLaDA 家族可达 50–73 个百分点）。

- **优于同预算/更高预算的 self-consistency**：Table 2 中 PDC 在 14/15 设置最优或并列最优，13/15 优于 INIT ×4，最大增益 +9.25 点（LLaDA-1.5 / GSM8K）。
- **鲁棒性**：更换 unmasking 策略（origin / random remasking）后 PDC 仍全面最优；半自回归（block 32）设置下依然有效；$\tau=1.0$ 时 PDC 在 12/15 设置最优，平均超出 INIT ×4 达 4.98 点，且 PDC 平均精度随温度升高反而略升（65.35 → 66.16），而 INIT 与 INIT ×4 分别下降 4.58 与 2.07 点。
- **结论**：前缀条件重生成是 DLM 特有的、有效的测试时验证原语；其收益来自"利用推理过程的复现一致性"，而非单纯增加采样次数。

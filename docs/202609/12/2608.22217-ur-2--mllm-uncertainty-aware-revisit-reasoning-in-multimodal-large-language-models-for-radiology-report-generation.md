# UR²-MLLM 论文深度总结

## 1. 核心问题与研究动机

- **背景**：放射学报告生成（RRG）旨在从医学影像自动生成诊断叙述，缓解放射科医生的工作负荷。临床实践中，报告生成本质上是一个**不确定性下的决策过程**——医生会反复重访可疑区域、将视觉发现与先验知识交叉比对，逐步修正判读后才给出最终诊断。
- **现有范式及其缺陷**：
  - **纯文本推理**（图1a）：图像仅编码一次，整个推理在文本空间进行，推理轨迹与图像感知解耦，易导致错误累积与幻觉发现。
  - **静态视觉推理**（"Think-with-Images"，图1b）：如 MAIRA-2、BoxMed-RL，以整图或边界框作为静态视觉上下文，但视觉证据在生成过程中固定不变，**缺乏"何时重访"与"何处重访"的显式机制**，隐含地把感知视为确定性的，丢弃了对临床模糊病例至关重要的诊断不确定性，常产生过度自信或幻觉报告。
- **核心研究问题**：MLLM 能否学会**动态重访视觉证据**——基于自身不确定性决定何时重访，基于对应解剖区域决定何处重访？

## 2. 方法论

### 2.1 核心思想
提出 **UR²-MLLM**（Uncertainty-aware Revisit Reasoning MLLM），将诊断不确定性作为**视觉重访的显式触发器**，通过三阶段流水线渐进学习"感知不确定性 → 基于局部视觉证据推理 → 用强化学习精炼重访行为"。

### 2.2 任务形式化
- 给定胸片 $X \in \mathbb{R}^{H \times W \times 3}$ 与指令 $c$，目标是生成报告 $y=(y_1,\dots,y_T)$（含 Findings 与 Impression 两节）。
- 与传统 MLE 目标不同，UR²-MLLM 将目标重写为在多维奖励下最大化期望：
  $\theta^* = \arg\max_\theta \mathbb{E}_{(X,c)\sim D, y\sim\Omega_\theta}[R(y,X,c)]$，
  其中 $R = \lambda_1 r_{fmt} + \lambda_2 r_{acc} + \lambda_3 r_{coh} + \lambda_4 r_{vis}$。

### 2.3 Stage 1：不确定性感知（Uncertainty-aware Perception）
- **数据构建**：基于 Chest ImaGenome 的解剖区域边界框标注，仿照 CURV，将每个解剖区域与含模糊限制词（may、likely、cannot exclude 等）的报告短语关联，得到 (图像, bbox, 标签, 短语) 四元组，构成约 **101k 样本**的 $D_1$。
- **训练**：仅对响应 token 计算自回归负对数似然（式2）做 SFT，使模型获得"诊断犹豫表达与特定解剖区域绑定"的感知先验，产出 $\Omega_{\theta_1}$。

### 2.4 Stage 2：有据多模态推理（Grounded Multimodal Reasoning）
- **轨迹构建**：以 CURV 发布的文本 CoT 轨迹（⟨findings⟩/⟨thinking⟩/⟨impression⟩ 三元组）为基础，逐句扫描 ⟨thinking⟩，与 Stage 1 的短语–bbox 对匹配。命中时：(i) 改写句子加入模糊词与区域引用标记 ⟨obj n⟩；(ii) 插入结构化 detect 调用；(iii) 追加简短重访小结。轨迹形式为：
  $s_{1:i-1} \to \tilde{s}_i \to \text{detect}(g_n, b_n, P_n) \to r_n \to \cdots$
  其中图像被划分为 $H'\times W'$ 的规则 patch 网格，共 $P=H'W'$ 个，bbox $b_n$ 映射为 patch 索引集合 $P_n$。
- **Detect-and-Copy 机制**：受指针生成网络启发，扩展词表加入 $P$ 个 copy token $\{\langle copy_k\rangle\}$。设 $H_t$ 为解码步 $t$ 的隐藏状态，$V_k$ 为第 $k$ 个 patch 的视觉嵌入，copy logit 为缩放内积：
  $\ell^{copy}_{t,k} = \alpha \cdot (W_Q H_t)^\top (W_K V_k)$
  其中 $\alpha$ 为可学习温度。copy logits 与 LM logits 拼接后经**单一 softmax** 联合训练，模型自行决定输出文本 token 还是 patch 指针。由于无重叠输出空间，**无需 copy gate**。copy 后的 patch 嵌入直接作为下一步输入，形成锚定于重访区域的**学习式硬注意力掩码**，使后续推理自然接续视觉内容。训练目标为扩展词表上的响应掩码 NLL（式5），产出 $\Omega_{\theta_2}$。

### 2.5 Stage 3：经 RL 的临床忠实生成
- **视觉接地奖励**：从轨迹 $\tau$ 提取重访事件 $E(\tau)=\{(b_e, txt_e)\}$，用两个冻结的 BiomedCLIP 编码器 $\psi_v, \psi_t$ 计算区域与文本的余弦相似度 $s(b,txt)$。为消除领域级图文相关性带来的虚高，引入**同面积随机区域基线** $\bar{s}$ 做校准：
  $r_{vis}(\tau) = \frac{1}{|E(\tau)|}\sum_{e\in E(\tau)}[s(b_e, txt_e) - \bar{s}(b_e, txt_e)]$，若 $E(\tau)=\varnothing$ 则 $r_{vis}=0$。
- **优化**：以 $\Omega_{\theta_2}$ 为初始策略与冻结参考模型，采用 **GRPO**，损失含组内相对优势与 KL 惩罚（式7）。复合奖励融合格式 $r_{fmt}$、临床准确 $r_{acc}$、推理连贯 $r_{coh}$ 与视觉接地 $r_{vis}$。

## 6. 主要结论与发现

- **MIMIC-CXR（分布内）**：在 6 个 NLG 指标中的 5 个取得最优（BLEU-1 27.79、BLEU-2 16.20、BLEU-3 10.11、BLEU-4 6.73、ROUGE-L 32.67），METEOR 28.66 略低于 CURV 的 30.43；CE 指标全面超越 CURV：CheXbert Acc 78.67、Ma-F1 13.96、Mi-F1 62.96、RadGraph Ent.F1 27.72、F1 21.47。RadGraph F1 提升尤为显著，说明接地推理带来的是**临床忠实性**提升而非仅语言流畅度。
- **IU X-ray（分布外）**：全部 6 个 NLG 指标最优（BLEU-1 31.81、BLEU-4 7.11、METEOR 40.75、ROUGE-L 41.20）；CE 方面 CheXbert Acc 92.58、Ma-F1 8.45、RadGraph Ent.F1 37.87、F1 25.95 均最高，仅 CheXbert Mi-F1（74.15 vs CURV 74.36）微弱落后。表明模型学到的是**可迁移的"以视觉证据支撑推理"策略**，而非过拟合数据集模式。
- **消融结论**：
  - Stage 1 单独会轻微降低 NLG（因其专注结构化不确定性枚举），但临床 F1 从 4.75 大幅升至 12.35。
  - 关闭动态重访（w/o visual revisit）性能骤降（BLEU-1 10.72、临床 F1 3.87）；改用静态视觉（w/ static vision）仅达 BLEU-1 16.13、临床 F1 6.13，均远逊于动态重访设计。
  - 移除 $r_{vis}$ 导致 NLG 与临床效能双降（BLEU-1 ↓2.53、临床 F1 ↓0.96、Recall ↓1.75），说明**仅监督"重访何处"不够，奖励对区域与文本主张的对齐起互补作用**。
- **重访行为分析**：Stage 3 相比 Stage 2 在全部 5 项指标上提升，触发率由 25.5% 升至 51.6%（跨过 35.0% 的真实基率，从欠触发转为主动重访），召回率由 25.6% 升至 64.3%，说明 RL 阶段确实建立了**视觉接地**而非纯语言的重访策略；但绝对精确率与空间重叠仍有限。
- **不确定性词频分析**：训练使模型模糊词表"收窄"，模态词从 GT 的 likely 变为 appears（SFT 4.34‰ vs GT 2.03‰，GRPO 进一步升至 8.11‰），过度依赖少数通用模糊词的问题**在 Stage 2 SFT 即已形成**，GRPO 只是放大；而重访奖励主要影响中频段模糊

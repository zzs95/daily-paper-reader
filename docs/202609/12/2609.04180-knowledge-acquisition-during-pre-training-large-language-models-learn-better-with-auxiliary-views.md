# 论文总结：Knowledge Acquisition During Pre-training? Large Language Models Learn Better With Auxiliary Views

## 1. 核心问题与整体含义

- **研究背景**：现有预训练数据研究多关注语料层面的属性（去重、过滤、覆盖度、深度、质量、多样性），但忽略了一个更根本的问题——**知识应当以何种形式被表征（representation）**。对生物医学、法律等复杂领域而言，知识是多面且相互依赖的，如何"表述"知识远不如原子事实那样显然。
- **核心研究问题**：
  - **RQ1**：在自然语言中，知识应当如何被表征？
  - **RQ2**：应当与知识一同表征哪些"周边知识"？
- **关键概念区分**：
  - **辅助视图（auxiliary views）**：人类在学习和教学过程中自然产生的对同一知识的重新表述网络，如教科书、博客、论坛问答，它们不仅改变语言表层，还提供**不同语境与形式**下的概念性视角。
  - **释义/改写（paraphrasing）**：被作者界定为"单一视图的语言变体"，作为对照组。
  - **周边知识**分为两类：**语境知识（contextual knowledge）**（K 所引用的内容）与**先备知识（prerequisite knowledge）**（K 所预设的基础概念）。
- **整体含义**：作者主张，辅助视图是预训练成功的关键因素之一，可为"数据多样性为何重要"提供可操作的机制解释，并为低数据领域的合成预训练提供原则。

## 2. 方法论

### 2.1 核心思想
- 在**继续预训练（continued pre-training）**框架下，用受控实验隔离"知识表征方式"的因果效应：固定 token 预算，比较"重复原文 / 循环释义 / 释义＋辅助视图"三种训练混合。
- 关键假设：预训练语料天然充斥着同一知识的多种辅助视图，这解释了预训练的效果超出"质量/多样性"这类模糊维度。

### 2.2 形式化设定
- 自回归语言模型 $f_\theta$ 以最小化下一词预测损失为目标：

$$L(\theta) = -\sum_{m=1}^{M}\sum_{i=1}^{n_m}\log P(t_{m,i}\mid t_{m,<i};\theta)$$

- 知识记为 $K$，通过子语料 $C_K=\{d_i \in C \mid d_i \text{ 包含 } K \text{ 的信息}\}$ 可及；由于 $K$ 只能通过 $C_K$ 上的下一词预测获得，**如何构造 $d\in C_K$ 至关重要**。

### 2.3 关键技术细节
- **训练条件设计**（单批次知识注入 single-batch knowledge injection，遵循 Chang et al. 2024：文档塞入一次前向，批次其余部分用通用数据填充）：
  - **Source**：每个 batch 注入原始文档；
  - **Para. M**：循环注入原文与其 M 条释义（重复 $NM+1$ 次）；
  - **Para. M + Aux.**：在释义文档之外同时注入辅助视图（每批次含博客、教科书章节、Stack Exchange 问答）。
- **Token 匹配（token-matching）**：Para. M + Aux. 引入更多知识承载 token，因此对 Source 和 Para. M 做上采样，使所有条件看到的知识相关 token 数相同——结果是 Para. M + Aux. 分给原文直接重复的 token 更少。
- **视图合成**：释义用 GPT-4.1（温度 1，top-p 0.975，段落级、保留 LaTeX/法律/医学术语）；辅助视图与先备知识用 GPT-5 生成大纲、GPT-5-mini 生成正文。
- **探针构建（LAMA 风格 cloze）**：
  - **事实探针**：从知识承载句抽取 QA → 转为自包含完形陈述，答案为句末目标词；
  - **推理探针**：需综合一句或多句支撑句推断未明说的信息；
  - 流水线含预处理过滤、问题抽取、语境化、完形转换、精修、再过滤（平均剔除 15%）。
- **评价指标**：目标跨度的联合对数概率（Log-Prob）、教师强制下目标 token 的词表排名（Target Rank，多 token 取最差排名）、5-shot 约束解码的多选题准确率（MCQA）。
- **机制分析**：以 FFN（MLP）层为对象（参数占比大，且 Geva et al. 2021 表明其通道可视为 key–value 记忆），逐层/逐通道测量相对权重变化幅度（relative delta norm、cosine distance）与变化集中度（Gini 系数）。

## 6. 主要结论与发现

1. **重复是习得新知识的必要条件，释义进一步有帮助，但释义的收益随 batch size 增大而衰减**。
   - Source 约 20 次曝光后饱和并急剧退化（过拟合），Para. 9 能维持到约 40 次曝光；该效应仅在 7B 及以上出现，1B 时释义略有损害。
   - batch size 增大到 256 时二者几乎持平（释义收益来自防止退化，而大 batch 同样能防止退化，二者冗余）；batch 1,024 时释义无一致收益，而辅助视图仍保持显著优势。
   - **调和了前人矛盾**：Chang et al.（batch 2048）报告释义有害，Allen-Zhu & Li（batch 96）报告有益，二者恰好处于该 batch-size 区间的两端。

2. **在固定 token 预算下，把用于文档重复的 token 分配给辅助视图能提升理解与事实回忆**——即使是事实回忆这一"反直觉"的结果：尽管每个事实目标都是原文的逐字短语，模型看到原文的次数更少，表现反而更好。这说明**更广的概念理解直接促进具体事实的记忆**，而非"暴力记忆"。

3. **该优势随模型规模扩大而增强**：1B 获益甚微，7B→13B→32B 与 Source/Para. 9 的差距持续扩大（分领域趋势基本一致，仅医学事实探针为例外）。

4. **辅助视图的效果不依赖生成它们的教师模型强度**：11 种生成器配置下下游事实准确率稳定在 0.405–0.422（均高于 Para. 9 基线 0.396），与生成器规模（$r=-0.14$，$n=6$）及其自身领域知识准确率（$r=-0.24$，$n=10$，$p=0.50$）均不相关；gpt-oss-20B 领域知识最少却教得最好。但**生成的视图文本量**与下游准确率中度相关（$r=+0.62$，$p\approx0.04$）。结论：辅助视图更像**

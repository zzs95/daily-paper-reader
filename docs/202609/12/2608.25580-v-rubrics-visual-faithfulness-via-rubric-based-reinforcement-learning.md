# V-Rubrics：基于评分标准的强化学习实现视觉忠实性 —— 论文深度总结

## 一、核心问题与研究动机

- **问题定位**：视觉语言模型（VLM）能生成流畅回答，但常缺乏视觉证据支撑。一个无依据的物体、图表数值或中间推断，就足以让整体看似合理的回答失效，在图表、文档、示意图和密集场景中尤其致命。
- **核心论点**：作者将这一现象重新定义为多模态后训练中的**信用分配失败（credit-assignment failure）**，而非单纯的评测问题。
- **现有奖励的缺陷**：主流 RL 对齐流程把回答压缩为标量偏好、二元正确性标签或整体 judge 分数。这类奖励只能说明"答案是否可接受"，无法指出：
  - 哪些视觉事实有依据；
  - 哪些推理步骤有效；
  - 哪些指令约束被违反。
- **混合证据困境**：真实回答常同时包含正确识别、一处无依据推断、以及合格的格式——单一结果奖励无法区分"视觉理解正确但推理错误"与"视觉理解错误但碰巧答对"。
- **研究意义**：作者主张把视觉接地（visual grounding）从"事后评测诊断"转变为"结构化训练接口"。

## 二、方法论

### 2.1 核心思想
将参考回答分解为原子化的评分细则（rubric items），沿三个维度打分，并把细粒度分数转化为**逐项、前缀定位**的 RL 优势信号，用于 GRPO 训练。

### 2.2 三个评分维度
- **VF（Visual Faithfulness，视觉忠实性）**：陈述内容是否被图像证据支撑（物体、属性、关系、计数、可见文字、图表数值）。
- **RC（Reasoning Consistency，推理一致性）**：结论是否由观察到的视觉证据逻辑推出。
- **IF（Instruction Following，指令遵循）**：是否满足提示词的格式、风格与任务要求。
- 提示词中规定优先级为 **VF ≫ RC > IF**，且 VF 条目须占多数。

### 2.3 评分细则设计四原则
1. **视觉接地**：VF 条目必须指向可核查的图像证据。
2. **自包含**：单条标准可脱离完整参考答案被独立判定。
3. **覆盖性**：覆盖中间视觉事实与推理步骤，而非只看最终答案。
4. **重要性编码**：分为 `ESSENTIAL / IMPORTANT / OPTIONAL / PITFALL` 四类标签，前三种带 1–5 正权重，PITFALL 为负权重（-1 或 -2），表示应避免的幻觉或推理陷阱。

### 2.4 数据构建流程（V-Rubrics 50K）
- **来源**：17 个视觉接地数据集（AI2D、ChartQA、ChartQA-X、ChartX、ChartGalaxy、ChartNet、DocVQA、InfographicVQA、Geometry3K、GeoSynth Choice、MM-K12、PixMo-Count、ThinkLite、ThinkLite-Hard、ViRL39K、We-Math2.0-STD、We-Math2.0-Pro）。
- **Stage 1 规则过滤**：校验媒体与字段有效性、任务内容非平凡、语言质量、身份去重与严格内容去重。
- **Stage 2 拒绝采样**：用 SFT 策略对每条样本生成 8 个 rollout，以正确率 k/8 作为**模型相对难度**信号：
  - 0/8 → hard；1/8–5/8 → medium；6/8–7/8 → simple；**8/8 被丢弃**。
- **最终构成**：50,248 条样本 = 18,121 hard（36.1%）+ 25,306 medium（50.4%）+ 6,821 simple（13.6%）。
- **标注**：全部由 Gemini-3-Pro 在统一结构化多模态提示与协议下生成，共 352,938 条 rubric 条目（VF 209,436 / 59.3%，RC 101,369 / 28.7%，IF 42,133 / 11.9%）。

### 2.5 SFT 初始化
- 以 **Qwen3-VL-8B-Instruct** 为基座，沿用 OpenMMReasoner 的冷启动数据配方，在 **OpenMMReasoner-SFT-874K** 上微调，得到 π_SFT。
- 每次 GRPO 运行创建两份独立参数副本：可训练 actor `π_θ(0) = π_SFT`，冻结 KL 参考 `π_ref = π_SFT`。

### 2.6 奖励设计
- 验证器（LLM judge）对每条标准独立给出二元满足分 `s_j ∈ {0,1}`；PITFALL 写作"应避免"条件，故 s_j = 1 表示成功规避。
- 正权重条目按重要性归一化后提供部分信用：

  `R_rub(a,x) = Σ_{j∈I+(x)} ρ_j · s_j(a;x)`，其中 `ρ_j = w_j / Σ_k w_k`

- **PITFALL 否决机制**：一旦确认违反，则语义上否决答案分与正 rubric 分（传输/解析失败不算违反）。
- 与答案奖励融合（α = 0.5）：

  `R(a,x) = α·R_ans(a,x) + (1−α)·R_rub(a,x)`

- 另含标准二元格式奖励（正文省略）。

### 2.7 前缀定位的逐项信用分配（核心创新）
- GRPO 对任一评分分量 u 做组内标准化：`z(u) = (u − μ_u) / (σ_u + ε_z)`。
- 验证器在给出 s_j 的同时返回支撑该判定的回答句子，通过**部分比率模糊匹配**对齐到 token 端点 `t_{j,end}`，构造前缀掩码：

  `M_{j,t} = 1[ t ≤ t_{j,end} ]`

  无法可靠对齐的条目退化为整段序列级信用（`t_{j,end} = T_g`）。
- 最终 token 级优势：

  `A_t = α·z(R_ans) + (1−α)·Σ_{j∈I_sc} ρ_j·z(s_j)·M_{j,t}`

- **关键细节**：答案优势广播到全部有效 token；每条正 rubric 独立标准化并仅作用于其前缀；权重只归一化一次，掩码后**不重新归一化**；某条目若所有 rollout 判定一致则不产生梯度。
- 对比变体：标量序列级变体在组标准化前先把 R_rub 与 R_ans 聚合，退化为标准结果监督 GRPO。

## 六、主要结论与发现

- **通用/知识基准**：Overall Avg. 由 SFT 的 64.93 → 答案级 GRPO 的 66.25 → **rubric GRPO 的 68.04**；相对答案级 GRPO 再提升 **1.79 分（约 2.7% 相对）**，增益集中在 MMMU 与 MMMU-Pro。
- **视觉数学/图表/逻辑基准**：Overall Avg. 由 SFT 的 58.45 → GRPO 的 61.94 → **rubric GRPO 的 62.45**；相对 SFT 提升 **4.00 分（约 6.8% 相对）**，最强增益出现在 MathVision、DynaMath、WeMath、LogicVista。
- **知识均值**：从答案级 GRPO 的 59.35 提升到 61.88。
- **增益分布不均**：答案级 GRPO 在 MMBench-Dev、MathVerse V/O、CharXiv Reasoning 上仍更强，说明 rubric 奖励并非全面提升，而是**集中在依赖"接地中间推理"的任务上**。
- **机制解释**：多模态推理的失败往往是**局部的**，但后果只在最终答案处显现；rubric 把监督单元从"最终答案可接受性"改为"接地视觉事实 + 有效推理步骤 + 满足的指令约束"，因此更匹配错误结构。
- **总体主张**：未来 VLM 后训练应把视觉接地视为可复用的结构化训练

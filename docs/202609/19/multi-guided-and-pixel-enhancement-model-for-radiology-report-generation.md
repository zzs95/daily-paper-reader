## 1. 核心问题与研究背景

- **任务定义**：放射学报告生成（Radiology Report Generation, RRG）旨在根据给定的医学影像（如胸片）自动生成对正常与异常组织的临床描述文本，属于医学图像描述 / 跨模态生成任务。
- **两大瓶颈（作者在摘要中明确列出）**：
  1. **数据规模约束**：可用于训练的医学影像数据集规模有限，导致模型难以充分学习。
  2. **传统网络架构的模型容量有限**：常规编解码架构表达能力不足。
- **LLM 作为潜在解法及其双重挑战**：
  - 优势：深层架构、海量参数、大规模预训练数据。
  - 挑战一：**模态鸿沟**——医学视觉特征与 LLM 文本语义空间之间存在表征不匹配。
  - 挑战二：**领域偏移**——LLM 的通用语义空间与医学专业知识之间存在显著偏差。
- **额外的影像质量问题**：成像设备差异、数据传输中的信息损失，导致医学图像出现模糊与噪声干扰。
- **整体含义**：论文试图将 LLM 引入 RRG，并通过"像素级增强 + 跨模态对齐 + 领域微调"的组合，对 LLM 在 RRG 任务上做**针对性优化**，而非直接套用通用多模态大模型。

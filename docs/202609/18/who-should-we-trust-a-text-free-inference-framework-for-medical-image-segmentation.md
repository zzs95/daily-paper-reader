## 一、核心问题与研究动机

- **背景**：医学图像分割是临床诊断、疾病量化与治疗规划的基础环节。
- **技术脉络**：近年来兴起的**语言引导（language-guided）多模态分割**，通过引入临床报告/文本作为辅助监督信号，显著提升了分割性能。
- **关键矛盾（论文动机）**：这类方法在**训练阶段依赖文本**，但在**推理（部署）阶段，临床报告常常缺失、不完整或质量参差不齐**。
  - 由此产生一个被既有工作忽视的问题：**当文本不可用或不可靠时，模型究竟应当信任文本还是信任图像？**
- **研究意义**：该问题直接关系到多模态模型在真实临床流程中的**可部署性与鲁棒性**——真实场景中报告并非总能与影像同步获得。

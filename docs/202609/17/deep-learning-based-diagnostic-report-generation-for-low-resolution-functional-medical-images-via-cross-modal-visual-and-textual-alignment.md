## 1. 核心问题与研究动机

- **应用背景**：自动生成诊断报告对减轻医师工作负担、提升诊疗过程的可靠性与有效性具有重要价值，是医学影像 + 自然语言生成的交叉热点。
- **具体痛点**：现有报告生成研究多集中于 CT、X 光、病理等**高分辨率形态学影像**；而**核医学功能影像（如 SPECT 骨显像）**具有分辨率低、信噪比低、病灶表现为弥散性放射性浓聚等特点，导致：
  - **视觉表征能力受限**：低分辨率下细粒度病灶特征难以被通用视觉骨干网络捕获；
  - **跨模态对齐薄弱**：图像区域与报告文本（尤其是病灶级描述）之间的语义对应关系难以建立。
- **后果**：生成的报告容易停留在"模板化叙述"，缺乏临床忠实度（clinical faithfulness），难以直接用于诊断支持。
- **研究目标**：面向 SPECT 骨显像，构建一个统一框架，同时解决**域自适应视觉表征、细粒度图文对齐、解剖学引导监督**三个问题，产出可信、可解释的自动诊断报告。

## 2. 方法论

### 2.1 核心思想
以"**域自适应表征学习 + 细粒度跨模态对齐 + 解剖引导的层次化监督**"三位一体，模拟放射科医师"由整体印象到局部病灶"的粗到细诊断推理过程。

### 2.2 三大关键组件

- **DAVFE（Domain-Adaptive Visual Feature Extractor，域自适应视觉特征提取器）**
  - 三阶段设计：
    1. **ImageNet 初始化**：继承自然图像预训练的通用底层特征；
    2. **大规模无标注 SPECT 数据上的对比预训练**：缓解核医学标注数据稀缺、域差异大的问题，学习模态特异表征；
    3. **基于注意力的重校准**（从参考文献推测可能采用 CBAM 类通道/空间注意力）：增强病灶相关通道与空间响应。
  - 目的：在低分辨率、弱对比条件下提升模态特异性视觉编码质量。

- **FIAM（Feature Interaction Alignment Module，特征交互对齐模块）**
  - 显式建模**全局叙述语义**（报告整体描述）与**病灶级文本线索**（局部发现）之间的交互；
  - 通过双向/层次化交互实现**细粒度且临床一致**的跨模态对齐，使视觉区域与文本片段建立可解释的对应关系。

- **APGL（Anatomy-guided Progressive Granularity Loss，解剖引导的渐进粒度损失）**
  - 引入**从全局到病灶级的分层监督信号**；
  - 与医师"先整体、后局部"的读片逻辑对应，引导模型逐级细化生成内容，减少漏诊关键病灶描述。

> **注**：摘要未给出各模块的具体网络结构、损失函数数学形式、注意力实现细节与训练算法流程；这些内容需查阅正文。

## 7. 优点（方法与实验设计亮点）

- **问题选择有实际价值**：直面核医学功能影像"低分辨率 + 标注稀缺"这一被主流报告生成研究忽视的场景，而非在成熟的胸片数据集上做增量改进。
- **域自适应预训练思路合理**：以"ImageNet 初始化 → 大规模无标注 SPECT 对比预训练 → 注意力重校准"三步走，针对性地缓解医学小样本与域偏移问题，且利用了易获取的无标注数据。
- **对齐粒度设计精细**：FIAM 同时处理全局叙述语义与病灶级文本线索，避免只做图像-整句的粗对齐，契合报告中"结论 + 描述"的分层结构。
- **监督信号符合临床认知**：APGL 的由粗到细渐进粒度监督，把医师的读片推理过程显式编码进损失函数，是"临床知识引导深度学习"的较好范例。
- **评价体系有创新**：在通用 NLG 指标之外引入面向病灶定位的层次化临床效能指标，并配合人工评估，评价更贴近真实临床需求。
- **可解释性受到重视**：可视化分析用于展示模型关注区域与文本的对应关系，有助于建立临床信任。

## 1. 核心问题与整体含义

- **研究背景**：放射学报告生成（radiology report generation）几乎完全在2D胸部X光片（chest radiograph）上发展成熟，当前SOTA系统（MAIRA-2、LLaVA-Rad、CheXagent等）均围绕该模态构建、训练和验证。领域默认的改进路线是"更大的骨干网络"或"在医学数据上预训练"。
- **核心质疑**：作者在3D多序列脑部MRI这一"体积化、多疾病"的新场景中重新审视上述假设，发现**模型本身不是杠杆**。
- **问题所在**：
  - 脑部MRI研究与胸片本质不同：一次检查包含多个共配准的3D体积（不同组织对比度），病变是体积性和偏侧性的，真实语料横跨胶质瘤、脑膜瘤、急性卒中、白质高信号等差异极大的疾病。
  - 一个脑部MRI研究通常有数百个切片（如急症卒中研究含496个轴位切片），但VLM提示中往往只携带3个切片（约0.6%的信息）。
  - 临床上报告的决策价值集中在少数关键发现：病灶位置、左右侧、结构是否移位及方向、最可能的诊断。**文字流畅但内容错误**的输出不会自我暴露其不可靠性（如图2所示：已发布系统将右额叶胶质母细胞瘤描述为左半球、反转中线移位方向、甚至描述心脏和气管等胸部结构）。
- **核心结论性主张**：在3D脑部MRI上，**注入提示中的信息（grounding information）而非模型选择，才是报告质量的主导可控因素**。

## 2. 方法论

### 2.1 核心思想

PerFact（Perception-Derived Fact Prompting）将问题分解为两个阶段：

1. **上游3D感知**：用上游3D分割与分类模型读取完整的体积数据（全部数百个切片），输出结构化潜在摘要 $z_i = h_\phi(X_i)$，包含分割掩膜、病灶属性、疾病标签。
2. **确定性序列化 + 提示级接地**：用确定性序列化器 $\psi(\cdot)$ 将 $z_i$ 转换为紧凑的**事实句子** $s_i = \psi(z_i)$，作为提示级接地信息喂给视觉语言生成器，让VLM只做它可靠完成的任务——**把结构化事实渲染为流畅的临床文本**。

形式化：数据集 $D = \{(X_i, y_i, Q_i)\}$，$X_i$ 为多序列脑部MRI研究，$y_i$ 为目标报告，$Q_i$ 为封闭式VQA对。在固定骨干、划分、目标报告集和解码策略下，建模 $p_\theta(y_i \mid X_i, G_i)$，核心问题是**哪种 $G_i$ 选择最优**。

### 2.2 上游3D感知

- 多任务网络，四项预训练任务：病灶分割、缺失模态补全、图文匹配、属性分类。
- 上游损失：$\mathcal{L}_{up} = \lambda_{seg}\mathcal{L}_{seg} + \lambda_{cmp}\mathcal{L}_{cmp} + \lambda_{itm}\mathcal{L}_{itm} + \lambda_{cls}\mathcal{L}_{cls}$
- **三阶段课程学习** $S_1 \to S_2 \to S_3$：$S_1$ 纯图像预训练 → $S_2$ 加入图文对齐 → $S_3$ 加入分类监督；每个阶段**从头训练**而非热启动，避免阶段效应与额外优化混淆。
- 对非肿瘤数据集（掩膜为二值而非多区域），使用各数据集独立的二值病灶分割器（避免把肿瘤标签体系强加于卒中和白质疾病）。

### 2.3 序列化器

从 $z_i$ 中提取疾病相关字段：偏侧性、病灶负荷、病灶体积、脑叶、强化模式、预测疾病类别，分组为 $f_i = [f_i^{loc}, f_i^{vol}, f_i^{attr}, f_i^{cat}]$，拼接为自然语言句子。粗粒度字段（侧别、体积带、负荷）跨疾病共享，细粒度字段（多区域体积、强化模式）仅在标注支持时产生，保证注入提示的人类可读性。

### 2.4 检索与提示构建

- **事实句子同时充当检索查询**：$u_i = e(s_i)$，$e(\cdot)$ 为图文匹配预训练学到的冻结文本编码器。
- **病例检索（CR）**：在训练集 $T$ 中，于同疾病家族内检索 top-k 报告，$R_{CR}(i) = \text{TopK}_{j \in T, d_j = d_i} \text{sim}(i, j)$，查询病例排除自身邻域。
- **知识检索（KR）**：在整理好的神经影像知识库 $B$ 中检索，$R_{KR}(i) = \text{TopK}_{b \in B} \cos(u_i, e(b))$。
- 最终提示 $P_i = [\text{IMG}(X_i); \text{INST}; G_i]$，其中接地块 $G_i$ 有7种形式：
$$G_i \in \{\varnothing,\ R_{KR}(i),\ R_{CR}(i),\ s_i,\ s_i^*,\ s_i \oplus R_{KR}(i),\ s_i \oplus R_{CR}(i)\}$$
- **PerFact 条件即最简单的非空情况 $G_i = s_i$**。

### 2.5 训练目标

- 用 **LoRA** 适配通用VLM骨干，基座冻结。
- 混合目标 $\mathcal{L} = (1-\rho)\mathcal{L}_{rep} + \rho \mathcal{L}_{vqa}$，主设置 $\rho = 0.2$。
- 报告损失为标准自回归负对数似然；VQA损失为答案字符串上的token级交叉熵。
- **封闭式VQA不采用自由生成评分**：在答案位置读出yes/no token概率质量并归一化，优化模型将更高质量分配给正确答案。

## 2. 方法论：AVP2CD 分层后训练框架

- **核心思想**：将报告学习分解为从解剖到诊断的层级后训练流程，缓解配对多模态数据稀缺导致的端到端训练困难。
- **基础模型**：Qwen2.5-VL-3B-Instruct。
- **三阶段/分层流程**（据摘要）：
  - **解剖视觉感知（Anatomical Visual Perception）**：通过“分割派生的解剖 grounding VQA”让模型习得解剖层面的定位能力，将基于分割的 grounding 与后续诊断推理连接起来。
  - **临床诊断（Clinical Diagnosis）**：从结构化腰椎 findings 构建诊断性 VQA，使模型学习病理描述与诊断性推理。
  - **报告生成精调（Report Generation Refinement）**：在私有配对矢状位 T1/T2 图像上，用强化学习进一步优化完整两段式报告生成。
- **强化学习奖励设计**：
  - 规则驱动的“临床—语义—格式”奖励，结合：
    - 实体级匹配；
    - BERTScore 相似度；
    - 报告结构合规性。
  - 采用 **DAPO 风格的非对称裁剪** 与 **截断完成掩码**，用于长文本报告的精调。
- **算法流程文字说明**：先用分割派生 VQA 建立解剖定位能力，再用结构化 findings 诊断 VQA 建立诊断描述能力，最后用多维奖励强化学习优化完整报告，使模型同时关注实体正确性、语义相似性和格式合规。文中未提供具体公式。

- AVP2CD 能从 Qwen2.5-VL-3B-Instruct 出发，显著提升私有 held-out 测试集上的报告生成分数。
- 分层后训练策略在低资源、配对多模态数据稀缺条件下有效。

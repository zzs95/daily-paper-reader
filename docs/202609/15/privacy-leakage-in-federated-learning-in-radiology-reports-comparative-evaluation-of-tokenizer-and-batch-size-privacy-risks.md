# 论文总结：放射学报告中的联邦学习隐私泄露——分词器与批量大小的隐私风险比较评估

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：联邦学习（FL）允许多家医疗机构在不共享原始患者数据的前提下协作训练模型，被视为满足 HIPAA、GDPR 等严格隐私法规的可行路径。然而 FL 并非绝对安全——客户端仍需上传模型梯度，而**梯度反演攻击（gradient inversion）** 已被证明可从共享更新中重建私有文本。
- **核心问题**：既往梯度反演研究多集中于通用 NLP 或医学影像领域，**放射学报告文本场景下的泄露程度尚不明确**；同时，领域专用 tokenizer（如 RadBERT）是否会因把临床术语编码为单一 token 而**加剧**可重建性，此前缺乏系统验证。
- **整体含义**：论文在受控条件下（固定模型架构，仅改变 tokenizer）首次系统量化放射学报告在 FL 梯度反演下的泄露风险，旨在为临床 FL 部署与隐私审计提供基准与指导。

## 2. 方法论

### 2.1 核心思想
- 采用**主动恶意服务器威胁模型**（worst-case）：服务器可修改共享模型架构、观测每轮每客户端梯度，且无 DP、无安全聚合、无梯度裁剪、无客户端完整性校验。
- 关键创新在于：**固定基础模型架构**，仅替换 tokenizer（GPT-2 / RadBERT / LLaMA-2），从而隔离"词汇切分方式"这一单一变量对隐私泄露的影响。

### 2.2 关键技术细节
- **模型**：GPT-2 风格紧凑 Transformer（3 层编码器，token 嵌入维度 m=96，8 个注意力头，前馈隐藏层 1536，约 1340 万可训练参数）；序列长度固定为 32 token。
- **植入探针（imprint module）**：服务器在 token embedding 之后、位置编码与注意力混合之前插入一个线性探针，形式为：
  - $y = W_2 \cdot \text{ReLU}(W_0 x + b_0)$，其中 $W_0 \in \mathbb{R}^{k \times m}$，$b_0 \in \mathbb{R}^k$，$W_2 \in \mathbb{R}^{m \times k}$，$k=1000$ 为探针分箱数。
  - 探针约占 19.3 万参数（约为基础模型的 1.4%），训练时联合优化。
- **闭式反演**：利用累积分箱（cumulative bin）设计，使每个 token 的贡献在分箱索引上结构分离，从而在仅观测批梯度和的情况下解析地恢复单样本嵌入：
  - $\hat{x}_j = \dfrac{\nabla W_{0,i}}{\nabla b_{0,i} + \epsilon}$，$\epsilon = 10^{-8}$，其中 $i$ 为该 token 唯一激活的分箱（经累积差分 $\nabla W_{0,i} \leftarrow \nabla W_{0,i} - \nabla W_{0,i-1}$）。
- **解码流程**：
  1. 对 $\hat{x}$ 做 L2 归一化，在对应 tokenizer 的嵌入表中用**余弦相似度**最近邻搜索解码；
  2. 当候选词余弦差距 < δ 时，用模型 LM-head logit（以已解码前缀为条件）进行消歧；
  3. 用匈牙利算法（scipy linear_sum_assignment）将恢复的嵌入与 32 个已知位置嵌入做最优分配，恢复位置顺序。
- **分词器**：GPT-2（50,257 词表）、StanfordAIMI/RadBERT（30,522）、LLaMA-2-7B（32,000）。

## 3. 实验设计

### 3.1 数据集 / 场景
- **Dischargesum**：98,206 份出院小结 + 368,751 份诊断报告；
- **MIMIC-CXR**：从约 22.7 万份自由文本报告中均匀随机抽取 1,500 份放射学报告（经 PhysioNet 授权使用）；
- 数据均匀随机划分到 **6 个模拟客户端**（近似 IID）。

### 3.2 实验变量与基准
- **自变量**：3 种 tokenizer × 3 种 batch size（64 / 128 / 256，指 32-token 序列数）。
- **重复**：每种配置独立重复 **5 次**，报告 95% CI 与配对 t 检验（df=4）。
- **评价指标**（作为信息恢复量而非文本质量）：
  - **Exact Sentence Accuracy**：重建 32-token 窗口与原始完全一致的比例（NFKC 归一化、小写化、空白折叠、保留标点）；
  - **S-BLEU**：1–4 元精确率 + 简短惩罚；
  - **ROUGE-L**：基于最长公共子序列的召回；
  - **MedGemma NER 临床概念重叠率**：语料级参考词表覆盖率（诊断、操作、解剖、药物），作为可识别泄露的上界估计。

### 3.3 对比方法
- 主要对比为 **三种 tokenizer 之间**的泄露差异，而非与既有攻击方法的性能对比；论文另以表格形式（Table 5）将本研究与 DLG、iDLG、TAG、Robbing the Fed 等既有工作做定性比较。

## 5. 实验数量与充分性

- **实验规模**：3 tokenizer × 3 batch size × 3 数据集（出院/诊断/MIMIC-CXR）× 5 随机种子 ≈ **135 个配置单元**；加上 NER 分析（3 tokenizer × 3 数据集 × 5 种子）与 27 组配对 t 检验（含 Holm 校正）。
- **充分性评估**：
  - **优点**：控制了模型架构、序列长度、嵌入维度、探针位置等变量，tokenizer 作为唯一自变量，实验设计较为干净；5 次重复并报告方差分解（batch size 贡献 94% 方差，tokenizer <1%）。
  - **局限**：仅有**单一可复现实验网格**（作者自述无独立验证实验）；未做非 IID 划分、未做更长序列（>32 token）、未做探针位置消融、未评估任何防御机制（DP、安全聚合等）；客户端数量固定为 6。
  - **公平性**：三种 tokenizer 使用相同的反演与解码超参数（无逐 tokenizer 调参），解码均使用各自嵌入表，公平性较好。

## 6. 主要结论与发现

- **泄露严重**：精确句重建率在 **27%–75%** 之间；batch size=64 时出院数据上 GPT-2/RadBERT/LLaMA-2 分别为 64.7%/70%/67.5%，batch size=256 时降至 27.3%/28.5%/27.5%。
- **S-BLEU 随 batch size 上升而下降**：出院报告从 0.69 降至 0.31；诊断 0.68→0.31；MIMIC-CXR 0.71→0.32。
- **Tokenizer 不是隐私保护杠杆**：27 组配对比较中，除 1 组外均不显著，Holm 校正后全部不显著（adjusted P=1.00）；平均精确句准确率三种 tokenizer 均为 48.3%，效应量 Cohen d ≤ 0.03。
- **Batch size 是主导因素**：方差分解显示 94% 的方差归因于 batch size。
- **临床概念泄露**：约 **75%** 的参考临床实体在重建文本中出现（GPT-2 75.1%、RadBERT 74.1%、LLaMA-2 72.9%），tokenizer 间无显著差异。
- **机理**：batch 增大导致分箱碰撞（bin collision）增加，反演得到的是多个嵌入的加权平均，解码偏向高频通用 token，临床低频术语先丢失，但重建呈"优雅退化"而非崩溃；即使在 batch size=256 下，个别轮次仍出现接近 batch size=64 的高保真重建。
- **临床 vs 直接标识符**：MedGemma 提取的是临床概念（诊断、操作、解剖、药物），而非 HIPAA Safe Harbor 列举的直接标识符（姓名、病历号等）；但作者强调 HIPAA 专家判定标准与 GDPR 的"间接可识别性"逻辑同样将临床上下文视为识别风险的一部分。

## 7. 优点

- **变量隔离干净**：固定模型架构、嵌入维度、探针位置、解码超参数，仅改变 tokenizer，是首个在临床放射学 NLP 领域做此受控比较的研究。
- **威胁模型刻画透明**：明确界定攻击者能力（C1 架构修改、C2 逐轮逐客户端梯度观测、C3 公开模型与 tokenizer 知识），并如实说明植入模块约 1.4% 参数增量使其**可被参数签名审计检测**，将其定位为部署策略缓解而非根本防御。
- **指标互补**：精确句准确率（严格上界）+ S-BLEU/ROUGE-L（部分恢复）+ MedGemma NER（临床概念覆盖），并对各指标的"上界/下界"语义做了清晰界定。
- **诚实的负结果**：作者预注册式地检验了"领域 tokenizer 会加剧泄露"的假设，并明确报告该假设**未被实证支持**，避免了事后合理化。
- **统计严谨**：5 次重复、95% CI、配对 t 检验、Holm 多重比较校正、三因素方差分解，并公开代码与逐种子结果。
- **可复现性**：数据源公开（Dischargesum、PhysioNet MIMIC-CXR），代码与配置在 GitHub 发布。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练时长与总能耗，难以评估实验的可扩展性与复现成本。
- **模型规模小**：仅 3 层、1340 万参数的紧凑 Transformer，作者亦承认结论**不能外推**到前沿规模基础模型（梯度稀疏性与噪声动态不同）。
- **序列长度受限**：32 token 远短于真实临床叙述；更长序列需按 B×L/k 线性增加分箱数 k，虽非指数障碍，但会使植入探针更易被检测——该权衡未被实证。
- **数据划分理想化**：采用近似 IID 的 6 客户端划分，未评估非 IID（站点特异性方案、人口偏斜）对梯度稀疏性与反演脆弱性的影响。
- **批内序列相关性**：同一报告被切分为多个 32-token 窗口，可能同时落入同一 batch，违反分箱碰撞分析所隐含的 IID 假设，可能高估或低估实际重建率。
- **NER 指标语义模糊**：基于语料级参考词表精确表面匹配，既非源报告对齐的实体恢复（上界），又因不做模糊/同义匹配而是语义恢复的下界，方向性解释需谨慎。
- **未评估防御**：完全聚焦攻击面，未实现 DP、安全聚合、梯度异常检测等任何缓解措施，也未给出效用-隐私权衡曲线。
- **单次可复现实验**：所有数值来自一次实验网格执行（虽可重跑），无独立验证实验。
- **定性示例使用 oracle 对齐**：表格中的重建结果按 oracle 位置对齐展示，真实攻击者只能观测无序/部分有序的 token 集合，示例的可读性高于攻击者实际能力。
- **临床效用未直接评估**：论文声明临床效用"从既有工作中推断"，未在本研究中实测下游任务性能。
- **外部效度**：仅覆盖英文公开去标识化语料，未涉及多语言、真实生产环境中的多模态数据（影像+文本）或运营元数据。

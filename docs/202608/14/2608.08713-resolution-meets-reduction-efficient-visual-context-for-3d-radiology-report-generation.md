## 1. 核心问题与研究动机

- 放射科医生诊断负荷在过去二十年急剧增加，3D CT 扫描的判读是临床中最耗时的任务之一，自动化报告生成具有重要价值。
- 视觉语言模型（VLM）为放射学报告生成提供了可行路径，但将现代 VLM 直接应用于完整 3D CT 容积面临巨大计算瓶颈：基础视觉编码器（VE）可产生数万甚至数十万的视觉 token，远超 LLM 可承受的上下文长度。
- 已有解决方案（如固定网格降采样、ROI裁剪、切片选择）要么牺牲解剖覆盖，要么丢失空间细节，可能导致漏报临床相关发现。
- 核心**开放设计问题**：在保持 LLM 接收的视觉 token 预算固定的前提下，token 预算应如何在**输入视野范围（FOV）**、**空间分辨率**和**视觉到语言投影器（vision-to-language projector）的压缩能力**之间分配？本文是首个对此进行系统控制性研究的论文。

## 2. 方法论

### 2.1 整体架构

- 采用标准 LLaVA 风格的三阶段 VLM 架构：**冻结的预训练视觉编码器（VE）** → **视觉到语言投影器** → **LoRA 适配的 LLM**。
- VE 产生 N 个视觉 token，投影器将其映射为 M 个 LLM 嵌入空间的 token（M ≤ N），再与文本指令一起输入 LLM，自回归生成放射学报告。
- 除非特别说明，对比实验中固定 LLM，仅变化投影器架构。

### 2.2 投影器分类

按压缩机制分为三类：

- **基于网格（Grid-based）的投影器**：按轴向 reduction 因子 r=(r_x, r_y, r_z) 将相邻视觉 token 分组聚合，保留空间拓扑结构。
  - **AveragePool**：对局部块做平均池化，简单有效，但在高压缩比下丢失细节。
  - **ConcatAdapter**（类似 Qwen3-VL）：将块内 token 沿特征维拼接，不提前聚合信息，但投影层输入维度（参数数量）随压缩比线性膨胀。
  - **TokenPacker**：用低分辨率插值网格作为 query，以原始高分辨率特征作为 key/value，每个输出 token 从对应空间区域聚合细粒度信息。
- **基于查询（Query-based）的投影器**：使用固定数量 L 个可学习 query，通过交叉注意力从全部 N 个 token 中聚合信息，输出长度与输入分辨率解耦。
  - **AttentionPool**：单层多头交叉注意力。
  - **PerceiverResampler**：多层 Perceiver 结构（交叉注意力 + MLP + 残差），query 间可交换信息，支持更深层迭代聚合。
- **Token 保持基线（MLP）**：LLaVA 式逐 token MLP 投影，M = N，无压缩，作为无压缩参考基线。

### 2.3 Token 预算匹配

- 不同 VE 和预处理配置下原生 token 数量差异巨大。为确保公平对比，**在同一 VE、同一预处理配置、同一压缩比下，所有投影器输出给 LLM 的 token 数量保持一致（M 相同）**：网格型通过 reduction 向量 r 控制，查询型通过设置 L = M 实现。

### 2.4 输入预处理与高分辨率策略

- **ROI 裁剪**：使用 TotalSegmentator 自动提取目标解剖区域（CT-RATE 用肺叶包围盒，Merlin 用全身前景包围盒），裁剪后有效分辨率提升。
- **Primus-4B（多块编码）**：将 ROI 划分为 4 个 192³ 的非重叠块分别编码后重组，使有效空间分辨率翻倍。
- **Curia-64S（更密集轴向特征）**：将 Curia 的 192 个轴向切片聚合为 64 个轴向特征图（而非基线的 8 个），保留更丰富的轴向细节。

### 2.5 训练策略

- 两阶段线性 warm-up：第一阶段仅训练投影器，第二阶段联合优化 LoRA 与投影器，各占 6.25% 总步数；PerceiverResampler 的投影器 warm-up 延长至 25%。
- 优化器为 AdamW，LLM 用 LoRA（r=32, α=64, dropout=0.1），CT-RATE 训练 16 epoch，Merlin 训练 32 epoch，按验证集临床 macro F1 选择最佳检查点。

## 3. 实验设计

### 3.1 数据集与评估基准

- **CT-RATE**（开发集）：50,188 个非增强胸部 CT 容积，25,692 个图文对，22,590/1,530/1,564 训练/验证/测试分割，评估 18 类心肺异常（RadBERT 分类器）。
- **Merlin**（跨数据集验证）：25,494 个腹部 CT-报告对，19,361/1,000/5,125 训练/验证/测试分割，评估 30 类腹部异常。作者微调 ModernBERT 分类器（95.7 macro F1），用 GPT-OSS-120B 自动提取的标签做教师信号。
- **主要评估指标**：临床 macro F1（主要），辅以 BLEU 1-4、METEOR、ROUGE-L 等词法指标（仅做最终对比，不参与模型选择）。

### 3.2 对比矩阵

- **4 个视觉编码器**：Primus（3D ViT, MAE）、Curia（2D ViT, DINOv2）、Merlin（3D ResNet, CLIP）、CT-FM（3D SegResNet, SimCLR），覆盖 CNN 与 ViT、2D 与 3D、不同预训练目标和规模。
- **6 种投影器**（含 MLP 基线）：AveragePool、ConcatAdapter、TokenPacker、AttentionPool、PerceiverResampler，压缩比从 4× 到 64×。
- **5 个 LLM**：Qwen3-1.7B、Qwen3-VL-2B、Qwen3-VL-4B、Phi-4-mini、Gemma-3-4B（1.7B–4B）。
- **3 种输入设定**：Whole（完整容积）、ROI（解剖裁剪）、High Res.（ROI + 高分辨率编码）。

## 4. 资源与算力

- 论文明确报告：整个研究约消耗 **60,000 A100 GPU 小时 + 6,000 H100 GPU 小时**，训练在 4-GPU 节点（A100 40GB 或 H100 80GB）上进行，单次运行使用 4–12 个 GPU。
- 最长的单次训练为 Primus MLP 基线，约 **240 H100 GPU 小时**。
- 超参搜索仅在 CT-RATE 上对 Primus-1B 进行，其他 VE 和 Merlin 直接迁移超参，未额外调优。

## 6. 主要结论与发现

- **ROI 裁剪是最一致的改进策略**：在 20 个配置中 19 个带来 F1 提升，平均提升 Primus +3.7、Curia +1.1。Primus 受益更大（从 Whole 到 ROI 的提升幅度），Curia 因已接近原生面内分辨率而提升有限。
- **更高分辨率不是免费午餐**：token 预算固定时，高分辨率必然伴随更高压缩比（实验中为 32×），平均反而导致 CT-RATE -1.2、Merlin -1.1 F1 的下降。只有 **TokenPacker 和 PerceiverResampler** 能有效利用更高分辨率，在 3/4 的 VE-数据集组合中取得最佳结果。
- **视觉编码器是主导因素**：最佳与最弱 VE 之间平均相差 15.0（CT-RATE）和 16.1（Merlin）F1，远大于投影器（2.35–4.47 F1）和 LLM 选择（2.2–5.3 F1）的影响。ViT 类编码器（Primus、Curia）全面优于 CNN 类编码器（CT-FM、Merlin）。
- **大多数压缩投影器无法匹敌无压缩 MLP 基线**：MLP 在 Primus 上最好（48.9/49.2）；PerceiverResampler 在 Curia 64× 压缩下超越 MLP（49.2 vs 48.5），是压缩场景下最稳健的投影器。
- **ConcatAdapter 在深度压缩下失效最明显**：其参数量从 8× 压缩的 39.4M 膨胀到 64× 压缩的 369.2M（9.4×），带来优化负担，在 Merlin 上 64× 压缩相对 8× 掉 10+ F1。
- **LLM 的视觉-语言预训练有正向作用**：参数相同的 Qwen3-VL-2B 全面优于 Qwen3-1.7B（0.6–4.1 F1），且参数规模不是性能预测因子。
- **最佳配置达 SOTA**：CT-RATE 49.5（Curia-64S + PerceiverResampler + Gemma-3-4B，对比最强 AdaRAG-CT 48.0）；Merlin 49.0（Primus-1B + MLP，对比 Jolia 23.8）。
- 高分辨率对小病灶的检出尤为关键（如 Merlion 中的肾囊肿和胆结石），类级别分析验证了分辨率对空间小病理的价值。

## 7. 优点与亮点

- **首个控制性研究**：首次在匹配 LLM token 预算的前提下，系统隔离 FOV、分辨率与投影器三个设计维度，研究问题清晰、实验设计严谨。
- **广泛的覆盖矩阵**：4 VE × 6 投影器 × 5 LLM × 2 大数据集 × 多压缩比，是目前该领域最全面的评估之一，且 3 个种子取均值保证统计可靠性。
- **公平的对比机制**：token 预算匹配消除序列长度混杂因素，使投影器间的比较有实质意义。
- **临床优先的评估视角**：以临床 macro F1 为主要指标而非词法指标，并论证了词法指标的局限性，评估更贴近临床价值。
- **发布临床评估工具**：为 Merlin 数据集微调并发布 ModernBERT 30 类异常分类器（95.7 F1），解决 Merlin 缺少高效临床评估模型的缺口。
- **可复现性强**：训练策略、优化器、warm-up 方式、超参搜索流程等细节披露充分，计算资源开销透明。

## 8. 不足与局限

- **视觉编码器冻结**：研究只覆盖"适配"场景而非"表征学习"，VE 不可训练限制了结论的适用面。
- **超参搜索不完整**：全面搜索仅在 CT-RATE/Primus-1B 上执行，其他配置为超参迁移，性能是下界，与开发配置的比较混杂了调优投入差异。
- **LLM 超参未重调**：5 个 LLM 共享为 Qwen3-VL-2B 调优的学习率，导致 Gemma-3-4B 在 Merlin/Primus 组合上可复现地崩溃至 20.5 F1；若单独调优，LLM 间的差距可能更小。
- **临床标签的教师误差**：CT-RATE 用 RadBERT，Merlin 用 LLM 提取标签训练的 ModernBERT，两者均有噪声，macro F1 衡量的是对"有缺陷教师"的忠实度而非真实临床金标准。
- **性能不足以临床部署**：最优模型 precision/recall 约在 50% 左右，论文明确承认这些系统仅用于设计选择对比，不可部署使用。
- **编码器因素混杂**：4 个 VE 在架构、预训练目标、数据规模、原生 token 数量上同时不同，无法分离各因素独立贡献。
- **ROI 裁剪的自定义性**：CT-RATE 的肺裁剪可能移除参考报告中其他器官的发现，产生结构性偏差，且需要额外的分割前处理步骤。
- **词法指标对比缺失**：与部分 SOTA（如 COLIPRI-CRM）相比，未报告完整词法指标，对标完整性略受影响。

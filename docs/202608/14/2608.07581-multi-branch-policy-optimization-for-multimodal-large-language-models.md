## 1. 核心问题与研究动机

本文关注的是**多模态大语言模型（MLLMs）的强化学习（RL）训练**中存在的信用分配（credit assignment）问题。

- 现有基于组的 RL 方法（如 GRPO）采用**轨迹级信用分配**，即对一条响应的**所有 token 赋予同一个优势值（advantage）**，将推理过程视为单一线性 token 序列。
- 然而，多模态推理相比纯文本推理存在**更高的感知不确定性**：模型需要反复查看图像、验证中间解释，且不同的视觉依据（visual grounding）会导致不同的推理路径。这使得轨迹级统一赋分**严重不匹配**：一条响应中可能混合了错误中间段与后续修正段，统一优势会模糊关键决策点的学习信号。
- 随着训练推进，组内相对优势逐渐退化（relative advantage degeneration），即 rollouts 变得更相似后，优势值趋向于零，导致有效学习信号稀疏。作者定义了**有效优势比例（VAR，Valid Advantage Ratio）**来量化这一退化，并观察到 GRPO 的 VAR 持续下降（图 2）。

**核心含义**：需要一种能够感知多模态推理中"感知决策点"的、更细粒度的信用分配机制，让模型在视觉解释分叉处获得清晰的正/负学习信号，而非被整条轨迹的平均优势所淹没。

## 2. 提出的方法：Multi-Branch Policy Optimization (MBPO)

MBPO 是一个**基于树结构的 RL 框架**，核心思路是在"视觉-语言决策边界"构造推理树，让兄弟分支探索不同的视觉假设，并通过分支间相对优势进行段级（segment-level）信用分配。三大核心组件如下：

### 2.1 并行推理树构建（Parallel Reasoning Tree Construction）
- 将推理建模为一棵**多分支树** T = (V, E)：节点表示部分推理状态，边表示连续的推理片段。
- 采用**BFS（广度优先）并行扩展**：对每个节点一次性并行生成 K_d 个子分支（用一次 vLLM 批量调用），提高采样效率。
- **分支点检测采用"混合策略"**：
  - 当检测到特殊标记 `<look>`（视觉-语言边界标记）时，在该标记处切分为分支节点；
  - 否则使用固定 token 预算 M 进行固定长度切分。
  - 这既保证分支与语义边界对齐，又有足够的分支密度与可比较的兄弟节点。
- 叶节点奖励：`R(n) = r(x_n, y_n)`（与真实答案匹配的得分）；内部节点奖励自底向上取子节点均值：`R(n) = (1/|Ch(n)|) Σ R(m)`。

### 2.2 分支级优势分配（Branch-level Advantage Assignment）
- 每个节点对应一个推理子序列 `SubSeq(n)`，由父节点轨迹续接 M 个新采样 token 生成。
- 节点价值以递归方式估计（叶节点为真实奖励，内部节点为子节点均值）。
- 核心公式为**归一化的兄弟相对优势（sibling-relative advantage）**：

  `A_sib(n) = (V̂(n) − mean(V̂(siblings))) / (std(V̂(siblings)) + ε)`

  即在**相同前缀、相同 token 预算**下，将当前分支与兄弟分支直接比较，实现"谁更优"的相对信用分配，并配合白化（whitening）稳定数值。
- 这一机制让错误分支获得局部负优势、正确分支获得局部正优势（图 1），从而缓解相对优势崩溃。

### 2.3 时间回放缓冲区（Temporal Replay Buffer）
- 存储历史生成的推理子序列及其插入迭代时刻：`B_replay = {(SubSeq(i), t_i)}`。
- **时间窗口过滤**：仅保留年龄 `t − t_i < T_max` 的样本，避免策略漂移后复用过期数据。
- **问题均衡采样**：每个问题最多保留 S_max = 32 条子序列（超限则随机抽样），再打乱组成 mini-batch，防止少数问题主导训练。

## 5. 主要结论与发现

- **MBPO 显著超越强基线**：在 MMRL18K 大规模训练下，MBPO-Qwen-VL-7B 平均分 64.9，超出 Shuffle-R1-Qwen-7B（63.4）、MM-Eureka（60.7）等强基线；在 Geo3K 上 Qwen-3B 的 Geo3K 准确率比 GRPO 提升约 7.27 个百分点（49.91 vs 42.64），Math Avg 提升 2.89 个百分点。
- **有效缓解相对优势退化**：MBPO 的 VAR 在训练中始终接近 1.0，且优势密度集中于非零值；GRPO 的优势分布被零值主导，正/负成分波动剧烈。
- **促进自我修正行为**：MBPO 训练后自修正率从 13.3% 升至 60.9%，成功修正率从 4.7% 升至 29.8%，修正位置更早；GRPO/DAPO/GSPO 的自修正行为明显受限。
- **树结构带来有效探索**：6-6-6 树结构在效率-精度权衡上最优；更大的树（8-8-8）虽早期多样性更高，但需要更长训练才能追平 6-6-6。
- **混合分支策略最佳**：`固定 M=100 + <look>` 的组合优于单一策略，兼顾分支密度与语义对齐。

- **方法设计新颖且自洽**：将树搜索引入多模态 RL，以 `<look>` 标记对齐视觉-语言决策边界，兄弟分支相对优势实现段级信用分配，逻辑链条清晰。

## 7. 局限性与潜在风险

- **分支检测依赖启发式规则**：MBPO 依赖特殊标记 `<look>` 与固定 token 预算 M 的混合策略来界定分支点。对于未显式训练出 `<look>` 标记的模型或任务，该方法需要重新设计分支触发机制，泛化性受到一定限制。
- **奖励信号仍然稀疏且单一**：叶节点奖励仅基于最终答案的正确性，并未引入过程奖励或细粒度正确性判定。因此，在答案形式复杂、部分正确可得分的情况下，兄弟分支的相对优势可能无法准确反映真实质量差异。
- **树结构超参数敏感**：树深、每层分支数 K_d、片段长度 M 等超参数需要根据任务和数据规模调节。尽管 6-6-6 在本文场景下最优，但该方法没有提供自适应选择超参数的机制，迁移到新任务时需重新调参。
- **记忆与显存开销未被完全透明化**：尽管时间开销仅增加约 1%，但并行树构造需要在内存中同时缓存多个兄弟子序列，回放缓冲区也存储大量历史子序列，峰值显存和内存占用可能高于 GRPO，论文未报告这部分资源消耗。
- **验证范围集中于数学推理**：实验全部围绕数学、图表与视觉感知推理展开，未涉及对话、视觉定位、视频理解等更广泛的多模态任务，其通用性仍需进一步验证。

## 8. 总结

MBPO 针对多模态推理中轨迹级信用分配与感知不确定性之间的核心矛盾，提出了一种基于并行推理树的分支级优势分配方法。通过将视觉-语言决策边界显式建模为树的分支点，并以兄弟分支相对优势替代统一的轨迹优势，MBPO 有效缓解了相对优势退化问题，显著提升了模型在多模态数学推理上的性能，并促进了自我修正行为的出现。同时，BFS 并行扩展与时间回放缓冲区的设计兼顾了训练效率与样本多样性。尽管该方法在分支检测、奖励设计和超参数选择上仍有一定局限，但整体上的问题定位、方案自洽性和实验严谨性都为本领域提供了有价值的思路。

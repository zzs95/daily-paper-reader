## 2. 论文提出的方法论：FedPSC

- **核心思想**：基于“伪全局”模型，对客户端贡献进行序贯估计，并通过建立两种贡献（验证性能贡献与梯度贡献）之间的关联来优化联邦聚合。
- **总体流程**：
  1. 利用各客户端在验证集上的性能差异，估计所有客户端的“性能贡献”；
  2. 基于这些贡献构建一个“伪全局模型”；
  3. 结合伪全局模型与由“排除效应”（exclusion effect）生成的联合模型，估计客户端的“梯度贡献”；
  4. 建立性能贡献与梯度贡献之间的映射关系，得到更全面的客户端贡献度量；
  5. 引入梯度方向指数移动平均（Gradient Direction Exponential Moving Average）方法，使客户端模型训练同时整合全局通用知识与本地个性化信息。
- **关键创新点**：
  - 贡献评估从“单一指标”扩展为“性能贡献 + 梯度贡献”的双重估计；
  - 利用伪全局模型缓解真实全局模型不可得的问题；
  - 通过指数移动平均平滑梯度方向，兼顾全局一致性收敛与本地数据分布特性。

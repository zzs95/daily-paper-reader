# 中文总结：JustLLMGRPO

## 1. 论文的核心问题与整体含义
- **背景**：文本条件下的胸部X光（CXR）生成旨在根据报告衍生提示合成逼真且符合临床发现的图像。以往研究主要聚焦于生成器架构、领域适应或生成器的强化学习，将提示视为固定输入。
- **核心问题**：放射学报告是临床沟通文档，而非逐字图像描述，其中含有时间比较、不确定性、检查背景等不可渲染内容。这些非视觉性话语会稀释可见放射学发现的信号，导致现有生成器虽已适应CXR领域，却仍未被充分利用。
- **关键观察**：在冻结CXR适应的Sana生成器时，仅用未修饰的LLM一次性改写提示，即可将RadDINO-FID从54.225降至27.572（降幅49.2%）。这揭示了“提示表达”是一个被严重低估、未开发的优化维度。
- **整体含义**：提示策略优化可作为一种与生成器优化并列的独立优化轴，为文本条件CXR生成提供了新思路。

## 2. 论文提出的方法论
- **核心思想**：保持Sana生成器完全冻结，利用LLM（Qwen3-4B）作为提示策略，通过标准GRPO强化学习优化提示政策，使提示更聚焦于可渲染的放射学证据，同时保持与源提示的对齐。
- **技术流程**：
  1. **提示策略采样**：给定源提示c，Qwen3-4B策略πθ采样一组K=5个候选提示p，每个提示包含推理轨迹和最终<optimized_prompt>块。
  2. **匹配种子渲染**：所有候选提示和源提示控制共享确定性种子z_c，用冻结Sana生成候选图像I_k和源对照图像I_0,k，以控制随机性。
  3. **放射学感知奖励**：图像得分Q = 0.45·BioViL-T对齐(对源提示) + 0.10·CheXpert标签一致性 + 0.45·RadDINO保真度。
  4. **相对奖励映射**：计算Δ_k = Q(I_k) − Q(I_0,k)，再映射为分段奖励R_k（改进=1+Δ，近似持平=0.1，明确退化=0）。
  5. **GRPO更新**：组内标准化奖励得到优势A_k，使用裁剪代理目标（clip ratio 0.2）和反向KL正则（β=10⁻³）更新LLM，Sana和奖励模型冻结。
- **推理阶段**：训练后的LLM贪心解码生成一个优化提示，用于同一冻结Sana生成图像。

## 6. 论文的主要结论与发现
- 指令引导的LLM改写可在不更新生成器的情况下大幅降低RadDINO-FID（54.225→27.572），证明提示表达中存在大量未被发掘的性能空间。
- 无约束改写会降低BioViL-T源提示对齐（0.695→0.609），显示视觉聚焦与源语义保持之间存在权衡。
- JustLLMGRPO通过GRPO恢复对齐至0.696，同时RadDINO-FID进一步降至26.780，相较直接提示改进50.6%。
- 在CheXGenBench上达到分布覆盖（PRDC coverage 0.588）和下游效用（宏AUC 0.746）的最佳点估计，且下游分类在14个条件中全部达到最佳或并列最佳。
- 直接Sana-GRPO在相同奖励下反而使对齐升高但保真度、召回和覆盖大幅下降，说明优化位置（提示策 略 vs 生成器）对结果至关重要。

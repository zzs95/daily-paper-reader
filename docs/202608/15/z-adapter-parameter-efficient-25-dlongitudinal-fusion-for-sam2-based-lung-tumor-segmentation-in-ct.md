## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：可提示基础模型（promptable foundation models），尤其是SAM/SAM2系列，近年来极大加速了医学图像分割的发展。SAM2本身是面向图像和视频的2D分割模型。
- **核心问题**：将SAM2这类2D模型在CT体数据上**逐切片（slice-by-slice）**应用时，由于缺少切片之间的纵向（Z轴/深度方向）上下文，往往会产生**纵向闪烁（longitudinal flicker）**——即相邻切片输出的肿瘤掩膜形状不稳定、出现抖动或断裂，这会直接损害肿瘤体积测量精度，并影响下游放疗计划等临床应用。
- **整体含义**：本文提出了一种轻量级的**2.5D适配方案（Z-Adapter）**，在不重新训练或微调整个大模型的前提下，将纵向上下文信息注入冻结的SAM2编码器，以稳定相邻切片的预测结果，同时保持模型参数高效。其意义在于探索了**“基础模型 + 轻量适配器”在三维医学影像分割中的应用范式**，是连接2D基础模型与3D医学分割需求之间差距的一次有价值的尝试。

## 2. 论文提出的方法论

### 核心思想
- 冻结SAM2风格的基础编码器，仅训练一个轻量Z-Adapter和mask decoder。
- 通过**2.5D纵向融合**，让模型在预测每个切片时“看到”相邻切片的特征，从而抑制切片间的掩膜抖动。

### 关键技术细节
1. **k-slice窗口输入**：以连续的k个CT切片作为一个输入窗口，为模型提供纵向上下文。
2. **深度1D token mixing**：Z-Adapter沿切片轴（Z轴）对token序列做**depthwise 1D token mixing**，使得各切片的特征在切片方向上进行信息交换，从而实现跨切片的特征融合。
3. **参数高效微调**：**仅更新Z-Adapter模块和掩膜解码器**，基础编码器保持冻结，因此可训练参数量非常小。
4. **边界感知纵向一致性损失（boundary-aware longitudinal consistency loss）**：该损失函数用于抑制切片间分割结果不一致（flicker），同时通过边界感知机制避免对肿瘤边缘造成过度平滑，保留边界细节。

### 算法流程（文字描述）
> 输入k个连续CT切片 → SAM2风格编码器逐切片提取特征（冻结）→ Z-Adapter对多切片特征进行沿Z轴的深度1D token mixing，完成纵向融合 → 轻量适配器进行特征适配 → mask decoder逐切片输出分割掩膜 → 训练时联合优化分割损失与边界感知纵向一致性损失。

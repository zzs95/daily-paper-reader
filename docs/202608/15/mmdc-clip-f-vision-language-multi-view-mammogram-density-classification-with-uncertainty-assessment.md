## 1. 核心问题与整体含义

- **研究动机**：乳腺密度是乳腺癌筛查中公认的风险因素，同时也会影响乳腺X线摄影的敏感性。准确、可靠的乳腺密度分类对临床筛查具有重要意义。
- **现有方法局限**：传统深度学习（如 CNN）方法在乳腺密度分类中常面临 **类间区分能力差** 的问题，并且无法充分利用**多视图（multi-view）之间的关系信息**。
- **论文贡献**：提出一个两阶段框架 **MMDC-CLIP-F**，将视觉-语言预训练模型（CLIP）与多视图融合相结合，并引入不确定性评估，以提高分类性能和临床决策的可靠性。

## 2. 方法论

- **总体架构**：由两个核心组件构成：
  - **MMDC-CLIP**（Multi-View Mammogram Density Classification using Contrastive Language-Image Pretraining）
    - 利用 CLIP 的视觉-语言表示能力，对乳腺X线影像进行多视图特征融合。
    - 通过**语义提示（semantic prompts）** 注入乳腺密度相关的领域先验知识，增强特征的判别性。
    - 使用**随机数据增强** 缓解标注数据有限带来的过拟合问题。
  - **MV-ACN**（Multi-View Auxiliary Confidence Network）
    - 接收来自所有视图的**最终隐藏状态（final hidden states）**，通过**多头注意力机制** 生成校准的置信度分数。
    - 置信度可用于识别低可靠性的不确定病例，供放射科医生进行二次复核。
- **关键思想**：将 CLIP 的跨模态对齐能力迁移到医学影像中，并显式建模多视图间的依赖关系，同时输出可解释的置信度以支持临床决策。

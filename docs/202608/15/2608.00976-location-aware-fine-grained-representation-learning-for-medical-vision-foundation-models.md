## 摘要
细粒度视觉表示对于医学图像分析至关重要，尤其是当诊断相关的证据细微且空间局部化时。基于 transformer 的现代医学视觉编码器必须学习补丁级别的表示，以捕捉这些细微的发现，但现有的医学视觉基础模型通常产生粗粒度的全局表示，或依赖于计算成本高昂的密集注意力。本文提出了一种位置感知的细粒度表示学习方法，用于医学视觉基础模型，该方法在保持高计算效率的同时学习分辨性强的局部表示。我们的方法引入了一个补丁级对比目标，利用图像空间位置提供的内在位置信号，使模型能够关注局部诊断模式。大量实验表明，在多个医学影像基准上，我们的方法在少样本分类和分割任务上优于现有方法，同时显著降低了计算开销。

## 论文总结

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：医学图像分析中，诊断证据往往**细微且空间局部化**。基于 Transformer 的医学视觉编码器需要生成**补丁级（patch-level）** 的细粒度表示，使其**既具备临床语义（clinically meaningful）又具备空间一致性（spatially consistent）**，否则下游大型视觉-语言模型（LVLM）无法提供可靠、空间可解释的医学回答。
- **现有方法的不足**：现有医学视觉基础模型可分为三类，但均未同时满足上述两个特性：
  - **指令微调编码器**（如 Lingshu）：通过语言模型隐式获得临床语义，但缺乏补丁级空间一致性。
  - **图像-文本对齐编码器**（如 MedSigLIP）：仅提供图像级语义监督，空间定位不受约束，容易编码冗余结构（如导管）。
  - **自监督编码器**（如 RadioDINO）：空间一致性强，但缺乏语义监督，难以区分形态相似但临床不同的区域（如肝脏与心脏）。
- **关键观察**：指令微调的 LVLM 很大程度上继承了视觉编码器的补丁级特性，因此空间一致性必须在**视觉编码器层面**解决，而非通过后期指令微调补足。
- **研究意义**：通过位置感知的细粒度表示学习，在上游强化视觉编码器本身，为可靠、可空间落地的医学 LVLM 奠定视觉基础。

### 2. 方法论：核心思想、关键技术细节与公式

#### 核心思想
- **位置感知的细粒度表示学习（Location-Aware Fine-Grained Representation Learning）**：通过**临床内容与空间位置的双向预测**，使视觉编码器在学习临床语义的同时自然涌现空间一致性，**无需显式补丁级正则化或自监督增强**。

#### 总体架构
- 输入图像 I 依次经过：
  - **视觉编码器 g**（ViT，SigLIP2-400M，patch size 16，输入分辨率 512）→ 输出 patch 级特征 Z
  - **2×2 平均池化** → Z′
  - **N 个注意力池化模块** {aₙ}（MHA + LayerNorm + MLP + 残差）→ 得到 N 个池化表示 A′ₙ
  - **投影层 w** → 将池化表示映射到 LLM 嵌入空间，形成视觉 token H
  - **轻量级 LLM f**（Gemma-3-270M）→ 自回归生成输出 token

#### 训练目标（联合优化）
- **Grounding Loss（L_g）**：给定临床文本 T，预测目标边界框 B。
  - 公式：$L_g = -\frac{1}{|B|} \sum_{i=1}^{|B|} \log p_\theta(B_i | H, P_g, T, B_{<i})$
  - 作用：迫使 patch 特征在区域内空间连贯。
- **Grounded Captioning Loss（L_c）**：给定边界框 B，生成对应的临床文本 T。
  - 公式：$L_c = -\frac{1}{|T|} \sum_{i=1}^{|T|} \log p_\theta(T_i | H, P_c, B, T_{<i})$
  - 作用：使区域特征具有临床描述性。
- 最终目标：$L = L_g + L_c$

#### 关键设计细节
- 文本框坐标归一化为 [0, 1000] 的整数，序列化为字符串进行 token 化。
- 边界框按 x_min 升序排列以保持一致。
- 文本注释覆盖**124 类统一标签**（解剖结构 + 病灶）和**从放射报告中提取的短语**。
- LoRA 应用于视觉编码器（rank 16，q/k/v/o + FFN）和 LLM（rank 4，q/v）。
- 与 LocCa 的区别：不依赖检测器伪标签（跨模态难以泛化），改用人工整理的地面真值标注，并用预训练轻量级 LLM 替代从零训练的 decoder，以提供语言先验、支持大规模训练。

### 3. 实验设计

#### 数据集构建
- **MedG 训练数据集**：4.48M 图像-文本-框三元组，来自 84 个数据集，覆盖 7 种模态（CT、MRI、X-ray、超声、眼底、皮肤镜、内镜）。
- 数据来源：IMed-361M（81 个数据集）、TotalSegmentator CT/MRI、MIMIC-CXR（与 MIMIC-Ext-CXR-QBA 的 A++ 级注释配对）。

#### 下游评估数据集
| 任务类型 | 数据集 | 说明 |
|---|---|---|
| 感知中心（Phrase Grounding） | PadChest-GR | 胸部X光，双语标注，报告级文本-框对（测试集 604 张图像） |
| 感知中心 | TN5000 | 甲状腺超声，活检确认的良恶性标签+边界框（测试集 1,000 张） |
| 感知中心 | SegTHOR | 胸部CT，4类危及器官分割，转换为文本-框对（测试集 235 张） |
| 语义中心（VQA） | SLAKE | 642 张 CT/MRI/X光图像，14,028 个 QA（仅英文） |
| 语义中心 | VQA-RAD | 仅 Yes/No 子集，采用无泄漏划分 |
| 语义中心 | OmniMedVQA | 使用 CARES 开放访问子集（多模态选择题，仅保留问题和答案） |
| 区域级鲁棒性（SegTHOR-Cls） | SegTHOR 衍生 | 基于边界框预测器官标签，含5种扰动：肺窗、骨窗、光子饥饿、运动伪影、低剂量退化 |

#### 对比方法
- **通用视觉基础模型**：SigLIP2-400M、DINOv3-Large、V-JEPA 2.1-Large
- **医学视觉基础模型**：MedSigLIP、RadioDINO、MedSAM
- **SOTA 医学 LVLM**：CheXagent、MAIRA-2、RadVLM（PadChest-GR grounding）；Fleming-VL-8B、MedMO-8B-Next（SLAKE VQA，采用 LLM-as-judge 协议）
- **开放词汇检测模型**：MedROV（SegTHOR 外部验证，不微调）

#### 评测指标
- Phrase grounding：**F1@0.5**（IoU 阈值 0.5 下的精确率/召回率/F1）
- VQA 与区域分类：**准确率**（答案精确匹配）
- 扰动测试：熵、概率转移热图、PCA 特征可视化

### 6. 主要结论与发现

- **LoFi 在所有评估任务上一致优于通用/医学视觉基础模型和 SOTA LVLM**：
  - 感知中心任务（PadChest-GR、TN5000、SegTHOR）：F1@0.5 最高。
  - 语义中心任务（SLAKE、VQA-RAD、OmniMedVQA）：准确率最高。
  - 鲁棒性任务（SegTHOR-Cls）：在原始和所有扰动条件下均最优，且退化幅度最小；熵最低，特征漂移最小。
- **位置感知学习比自监督增强更鲁棒**：DINO 等自监督模型对预训练增强集之外的真实扰动（如窗宽改变、光子饥饿）更敏感；LoFi 不依赖增强，依赖临床文本-框对齐，在扰动下保持稳定。
- **两个训练目标具有互补性**：单独使用 captioning 在感知任务上不足；单独使用 grounding 在语义任务上不足；联合训练在两类任务上均达到最佳或接近最佳。
- **视觉编码器需要在上游强化**：指令微调 LVLM 无法弥补视觉编码器在 patch 级别上的缺陷；LoFi 证明了在上游编码器层面解决此问题的重要性。

### 7. 优点

1. **方法设计新颖**：通过 grounding + grounded captioning 让空间一致性与临床语义**联合涌现**，避免显式 patch 级约束，简洁且有效。
2. **大规模优质数据集**：构建 MedG（4.48M 三元组、84 数据集、7 模态），远超以往工作（如 CXR-only 或 600K 规模），并统一了标签体系（124 类）。
3. **丰富的定性+定量分析**：PCA / PaCMAP 可视化直观展示各编码器 patch 特征的空间一致性和语义判别力，为方法动机提供有力证据。
4. **评估全面严谨**：覆盖感知、语义、鲁棒性三个维度，对比多类基础模型与 SOTA LVLM；加入外部验证，增强泛化结论的可信度。
5. **实用可行性**：使用了轻量级 LLM 和 LoRA 微调，在单张 GPU 上可完成，降低了医学领域部署门槛。
6. **结论具有可推广性**：指出了“上游视觉编码器决定下游 LVLM 的视觉基础”这一方向，对医学 LVLM 的构建具有方法论启示。

### 8. 不足与局限

1. **扰动类型覆盖有限**：扰动集中在 CT 重建相关（窗宽、光子饥饿、运动伪影、低剂量），未覆盖 MRI 伪影、超声噪声、图像压缩等更广泛的临床干扰。
2. **下游任务范围偏窄**：评估集中在 grounding、VQA 和区域分类，未涵盖分割（pixel-level）、检测（多类目标）、报告生成等更广泛的医学视觉任务；与 MedSAM 等分割模型的对比也并非直接分割性能对比。
3. **数据构建可能存在噪声**：从分割掩码和报告自动提取的文本框可能不精准；标签归一化和跨数据集合并可能引入不一致（作者已做处理但无法完全消除）。
4. **对模型鲁棒性的分析有限**：熵和概率变化分析仅在 SegTHOR-Cls 的 4 类标签上展示，未扩展到其他数据集和更多类别。
5. **SOTA 对比语境的局限**：与固定 LLM-as-judge 协议相关的结果依赖 GPT 评判的主观性；与 RadVLM 的对比因测试数据已见而弱化了可比性。
6. **算力信息不完整**：未报告总训练时长、样本吞吐量、总 GPU 小时数，复现成本难以准确评估。

Title: OtosRG: A Prompt-Augmented Framework via Diagnostic Guidance for Otoscopic Report Generation

URL Source: https://link.springer.com/chapter/10.1007/978-981-92-3548-3_36

Published Time: 2027

Markdown Content:
## Abstract

Automatic medical report generation aims to translate medical images into clinically meaningful textual descriptions, providing effective support for clinical diagnosis . However, generating diagnostic reports from otoscopic images remains challenging due to subtle lesion patterns, large variations in anatomical structures, and the limited diagnostic reasoning ability of existing generation models. To tackle these challenges, a two-stage framework named OtosRG is introduced for generating oto-scopic reports. This framework fuses multi-scale visual perception with diagnosis-aware report synthesis. In the first stage, we introduce a Multi-scale Guided Intermediate Report Generator, which captures fine-grained visual abnormalities through multi-scale feature encoding and spatial attention, enabling the generation of intermediate reports that describe lesion-level findings of the tympanic membrane . In the second stage, we design a Diagnosis-Enhanced Report Generator, which learns discriminative diagnostic representations via contrastive classification and incorporates the predicted diagnosis together with intermediate findings to construct structured prompts for a large language model, guiding the generation of the final clinical report. Through comprehensive experiments conducted on the OCASD dataset, the proposed framework is shown to outperform existing approaches for report generation across various evaluation criteria. In addition, it produces diagnostic reports that exhibit stronger clinical coherence and greater informativeness.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **临床背景**：乳腺癌是全球女性最常见的恶性肿瘤和主要死因之一。经皮核心针穿刺活检（CNB）是乳腺癌诊断的初始关键手段，尤其用于不可触及病变。但CNB存在以下核心挑战：
  - 组织取样有限，难以反映病变整体异质性；
  - 诊断实体之间存在细微形态学重叠，尤其在不同机构间染色、扫描、报告标准差异下，亚型区分更加困难；
  - 判读高度依赖专家经验，工作量巨大。
- **技术背景**：现有病理基础模型（如PRISM）面向通用病理任务，并非专注于乳腺CNB诊断；多模态生成系统可以生成自由文本报告，但在高风险临床工作流中，缺乏可靠的**不确定性估计**和**弃权（deferral）机制**，难以保证安全临床落地。
- **核心意义**：本文旨在开发一个**乳腺专科病理基础模型（CorePath）**，通过配对CNB全切片图像（WSI）与诊断报告微调通用模型，提升乳腺CNB诊断准确性、跨机构鲁棒性，并进一步构建**风险控制报告生成框架（CorePath-CRG）**，实现对不可靠输出的选择性释放、回退和人工复核，从而提高AI辅助病理报告的安全性与临床可用性。

## 2. 方法论

### 2.1 核心思想
- 利用**两中心收集的7,901对CNB WSI-病理报告**，对通用病理基础模型**PRISM**进行**参数高效的Perceiver-only微调**，得到乳腺专科模型CorePath。
- 微调仅更新**slide encoder（Perceiver）**内部的少量适配器（adapter）参数，**文本编码器及跨模态组件完全冻结**，从而保留预训练模型的通用语言知识，同时迫使模型学习乳腺特异的病理视觉表征，防止过拟合到训练语料的文本模板。
- CorePath-CRG则在CorePath之上引入**conformal prediction**（保形预测）和**Learn-Then-Test（LTT）**风险控制，实现三层选择性输出机制。

### 2.2 关键技术细节
- **数据预处理**：WSI经背景/非组织区域剔除后切块，使用Virchow patch encoder提取特征；报告经DeepSeek-R1-Distill-Qwen-32B提取结构化诊断信息，再用OpenBioLLM-70B翻译为英文作为配对文本。
- **微调配置**：
  - 分布式训练：8×NVIDIA RTX 3090 GPU，6个epoch，per-GPU batch size=5，梯度累积16步，有效全局batch size=640；
  - 学习率2×10⁻⁴，权重衰减5×10⁻⁶；
  - 训练损失：对比损失权重1.0，蒸馏损失权重1.0，生成损失禁用（权重0.0）；
  - WSI最大tile数2560，随机采样tile；文本最大长度768 tokens；
  - 适配器bottleneck维度8，ReLU激活，dropout 0.0，残差缩放1.0；
  - 注入位置：Perceiver的第一个block第6层FFN（layers.0.tf.5.ff），以及第一、第二block的cross-attention FFN（layers.0.xattn.ff、layers.1.xattn.ff）。
- **零样本诊断分类**：通过预定义的文本提示（prompt）直接对slide进行分类，无需任务特定分类器。评估任务包括癌症检测、浸润评估、组织学亚型分类等。
- **CorePath-CRG报告生成风险控制**：
  - **第一阶段（conformal校准）**：对癌症检测，利用正确分类校准样本估计\(t_{\text{lower}}\)和\(t_{\text{upper}}\)阈值，概率落在中间则视为不可靠；对组织学亚型，使用top-1与top-2概率差（margin）作为非一致性分数，校准margin阈值\(t_{\text{margin}}\)，低于阈值的预测被标记为“Unknown”。
  - **第二阶段（报告评分与阈值校准）**：设计Self-Confidence Score（LLM审计器评估5个候选报告，维度包括乳腺相关性、诊断完整性、报告间一致性、信息对齐和语言连贯性），与conformal诊断margin融合得到释放分数\(S_i = P_i + \lambda M_i + \epsilon_i\)。校准阶段使用Judge Score（与参考翻译对齐）定义二元风险标签，通过LTT框架选择校准释放阈值，控制自动释放报告的风险率。
  - **第三阶段（三层选择性释放）**：
    1. \(S_i\)高于阈值 → 自动释放（trusted synthesis，由Synthesizer Agent综合生成简洁诊断）；
    2. 低于阈值但conformal分类结果保留 → 仅返回亚型标签（subtype-only fallback）；
    3. 两者均不确定 → 输出“Unknown”，转人工病理医生复核。
- **统计保证**：采用Clopper-Pearson精确置信界，在交换性假设下提供有限样本、分布自由的\(R_{\text{true}}(A_{k^*}) \le \alpha\)有至少\(1-\delta\)置信度；实验默认\(\alpha=0.10,\delta=0.10\)。

## 6. 论文的主要结论与发现

- **CorePath在分类性能上全面超过PRISM**：私有中心的五分类组织学亚型weighted AUC达到0.9526–0.9735；癌症检测weighted AUC 0.9669–0.9989；浸润评估weighted AUC 0.9643–0.9881。
- **公共基准也优于通用模型**：BCNB的浸润癌亚型分类weighted AUC为0.7780，BRACS病变分层为0.8178，BRACS细粒度分类为0.8252，均为三模型中最高。
- **报告生成幻觉大幅减少**：PRISM的非乳腺癌幻觉率为30.1%，CorePath降至2.8%，CorePath-CRG在已释放的输出中达到0%。
- **CorePath-CRG通过风险控制进一步提升临床报告质量**：LLM-based Evaluation Score在所有中心均显著高于CorePath，文本相似度指标在多数中心也最好，尤其是保守释放策略能保留高置信度报告，同时避免低置信度叙述释放。
- **LLM评价分数与病理医生评估高度一致**：Spearman ρ=0.911，ICC(A,1)=0.843，表明LLM-as-judge可作为报告质控的有效替代指标（但存在保守偏差）。
- **定性案例显示**：CorePath改善了乳腺领域适配性；CorePath-CRG在不确定时能正确弃权，且不会盲目拒绝可靠的良性病例。

## 7. 优点

- **领域专化+保留通用性**：Perceiver-only微调策略轻量、高效，既强化乳腺特异性表征，又保留预训练模型的语言与跨模态能力。
- **零样本灵活性**：无需为每个任务训练单独分类器，prompt即可适应不同诊断标签体系，适合临床层次化工作流。
- **风险控制机制创新**：将conformal prediction与LTT引入开放式病理报告生成，三层释放机制（自动释放/亚型回退/人工复核）直接回应临床安全需求。
- **多中心大范围验证**：覆盖6个私有中心、2个公共基准，且微调数据与测试数据严格分离，充分验证跨机构泛化能力。
- **报告质量评估严谨**：结合幻觉分析、LLM-judge打分、自动文本指标，并通过病理医生盲评验证LLM评分的有效性，增强了评估的可信度。

## 8. 不足与局限

- **回顾性研究设计**：缺乏前瞻性临床验证，无法评估真实工作流中的诊断准确性、时间成本、周转时间和用户信任。
- **微调数据来源有限**：仅来自两个中心（WCH-1、SPH-1），可能不足以覆盖更多样化的染色、扫描平台和报告风格。
- **统计保证依赖交换性假设**：conformal和LTT保证在分布漂移、工作流变化或模型/prompt修改后可能失效，需要持续再校准。
- **幻觉检测范围有限**：主要关注“非乳腺癌”幻觉，未系统检测肿瘤分级、生物标志物状态、左右侧、微浸润等细微但严重的事实错误（尽管Evaluation Score可能间接捕捉）。
- **LLM评分存在保守偏差**：Bland-Altman分析显示LLM分数平均值低于病理医生约0.08，且95%一致性界限较宽，可能低估高置信度报告质量。
- **计算效率细节缺失**：未报告推理时间、内存占用或部署成本，不利于临床落地评估。
- **未见消融实验或敏感性分析**：未评估不同适配器位置、不同Lambda权重、不同conformal alpha值等对性能的影响，也未见与其他领域专用模型或微调策略（如全量微调、LoRA）的对比。

## 论文详细总结

### 1. 核心问题与整体含义

- **研究动机**：医学影像分析中，影像组学（Radiomics）特征（如形状、强度、纹理等）通常由分割模型生成的预测掩膜计算而来，并进一步用于临床决策。然而，分割模型可能过度自信或校准不良，导致派生出的放射学测量值在表面上显得比实际更可靠。
- **核心问题**：如何为这些由分割掩膜导出的标量放射学目标提供具有统计保证、且区间足够窄（高效）的不确定性量化（UQ）。现有黑盒式不确定性方法（直接对预测放射学值构造区间）忽略了测量生成过程，未利用测试时的分割掩膜信息（如目标大小、拓扑、边界位置和分割不确定性）。
- **整体意义**：本文提出 ConRad，一个用于放射学特征的共形预测（Conformal Prediction, CP）框架，在保持有限样本边际覆盖保证的前提下，利用测试时信息构建自适应区间，显著提升区间效率，从而增强临床影像管线中放射学分析的可靠性。

### 2. 方法论

- **基本框架**：基于分割共形预测（Split Conformal Prediction）和共形分位数回归（Conformalized Quantile Regression, CQR）。
- **核心思想**：将放射学目标视为标量预测目标，但显式利用测试时从预测掩膜、输入图像、预测放射学值和边界不确定度推导出的协变量，来学习自适应的区间宽度。
- **技术细节**：
  - 对每个放射学目标，使用训练集拟合条件分位数模型 `Q̂_α/2(X)` 和 `Q̂_{1−α/2}(X)`。
  - 在独立校准集上计算非一致性分数：`R_i = max(Q̂_α/2(X_i) − Y_i, Y_i − Q̂_{1−α/2}(X_i))`。
  - 取校准分数中第 `⌈(1−α)(n+1)⌉` 小的值作为共形校正量 `q̂`。
  - 测试区间的形式为：`S(X_test) = [Q̂_α/2(X_test) − q̂, Q̂_{1−α/2}(X_test) + q̂]`。
  - 满足标准的分割共形保证：`Pr{Y_test ∈ S(X_test)} ≥ 1−α`（可交换性条件下）。
- **特征体系**（四个家族）：
  - **几何与拓扑**：预测掩膜的像素数、图像占比、连通分量数。
  - **强度分布**：ROI 内图像强度统计量（均值、标准差、最小/最大值、10%/25%/50%/75%/90% 百分位数）。
  - **预测放射学特征**：从 PyRadiomics 提取的形状、一阶强度、纹理/异质性特征。
  - **边界不确定性**：预测概率图在掩膜内、边界环带和全局的均值、标准差、百分位数，以及前景概率在 [0.4, 0.6] 区间的像素占比。边界环带通过掩膜膨胀与腐蚀之差得到。
- **目标过滤**：针对每个数据集，过滤掉频繁产生非有限值、观测样本过少、值近似常数或方差接近零的放射学目标，以保证评估的公平性。

### 3. 实验设计

- **数据集**：
  - HAM10000（皮肤镜图像）
  - Kvasir（内窥镜图像）
  - COVID-QU-EX（胸片）
  - TG3K（甲状腺超声）
  - TN3K（甲状腺结节超声）
- **目标数量**：经过滤后共保留 171 个放射学目标（各数据集分别保留 26、27、40、38、40 个）。
- **对比方法**（基线）：
  1. SCP：基于绝对残差的分割共形预测。
  2. CQR-ˆy：仅使用预测放射学值作为特征的 CQR。
  3. CQR-Generic：使用预测值 + 几何/拓扑 + 强度分布 + 预测放射学特征的 CQR。
  4. ConRad：在 CQR-Generic 基础上增加边界不确定性特征。
- **实验设置**：50 次随机训练/校准/测试划分，比例为 0.4/0.4/0.2；名义误覆盖水平 α=0.1；分位数回归使用岭正则化（ℓ2 惩罚 5×10⁻²）、Adam 优化器、1200 次迭代，超参数跨数据集/目标保持一致。
- **评估指标**：
  - 目标级胜率（Win Rate）：与最强基线比较。
  - 对称相对宽度改进（Relative Improvement）。
  - 经验覆盖率（Empirical Coverage）。
- **消融实验**：通过移除单个特征家族（几何/拓扑、强度分布、放射学、边界不确定性）重新拟合并校准模型，计算归一化消融重要性。

### 6. 主要结论与发现

- ConRad 在大多数数据集上显著提升了目标级区间效率：
  - HAM10000：平均相对改进 5.47%，胜率 82.5%
  - COVID-QU-EX：平均相对改进 4.94%，胜率 91.3%
  - TG3K：平均相对改进 5.83%，胜率 81.1%
  - TN3K：平均相对改进 2.03%，胜率 78.6%
  - Kvasir：平均相对改进接近零（−0.03%），胜率 55.3%，是最弱的数据集。
- **覆盖率**：ConRad 经验覆盖率接近名义 90%；最差目标均值覆盖率 89.9%，中位数覆盖率 90.2%-90.6%，171 个目标中 170 个达到至少 90% 覆盖。
- **消融结果**：边界不确定性是最大的效率贡献者，平均归一化重要性为 40.5%，平均正宽度增加为 4.95%，并在 9/15 的面板中占据主导地位（尤其是所有纹理特征面板）。说明分割边界不确定性提供了互补信息，超越一般图像和掩膜摘要。

### 7. 优点

- **方法新颖且实用**：首次将共形预测用于非体积型放射学目标的区间估计，显式利用分割输出的结构信息与不确定性。
- **理论保证强**：基于 CQR 的标准分割共形保证，无需重新训练分割模型，适用范围广。
- **特征设计合理**：四个特征家族覆盖了图像外观、掩膜几何、预测值和分割不确定度，能针对不同放射学目标自适应调整区间宽度。
- **评估协议严谨**：提出目标级尺度归一化评估（胜率与对称相对改进），避免了跨目标量纲不可比的常见陷阱。
- **消融诊断清晰**：通过特征移除实验直接关联最终区间宽度，而非仅依赖模型系数，解释性强。
- **基线比较公平**：以最强基线作为参照，并且保证覆盖率可比。

### 8. 不足与局限

- **只验证了 2D 场景**：未涵盖 3D 医学影像，而 3D 放射学特征具有不同的稳定性和采集依赖行为。
- **边际覆盖而非条件覆盖**：无法保证每个个体或亚组的条件覆盖率，高维特征下存在自适应区间局部不准确的风险。
- **可交换性假设**：面对数据集偏移、扫描仪偏移等实际场景，需要重新校准或额外诊断。
- **依赖概率图质量**：边界不确定性特征依赖分割模型输出的概率图，当概率图不可靠时，效率收益可能受限。
- **目标独立处理**：当前方法对每个放射学目标单独构建区间，未考虑多变量/结构化放射学特征之间的相关性，可能遗漏联合不确定性信息。
- **Kvasir 数据集上改进微弱**：说明方法在不同影像模态上的收益可能差异较大，通用性仍有待进一步探索。

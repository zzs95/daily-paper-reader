## Z-Adapter 论文总结

### 1. 核心问题与研究动机

- **研究背景**：以 SAM（Segment Anything）和 SAM2 为代表的可提示基础模型在医学图像分割中展现出强大的泛化能力，在 2D 场景下大幅减少了标注和训练成本。
- **核心问题**：CT 是三维体积数据，而 SAM2 本质上是 2D/视频模型。在肺肿瘤分割中若逐切片（slice-by-slice）应用 2D 模型，会产生 **“纵向闪烁”（longitudinal flicker）** 现象——即相邻切片之间肿瘤掩膜（mask）出现不稳定的跳变，具体表现为：边缘抖动、分割目标突然出现/消失、面积剧烈波动等。
- **危害**：掩膜跨切片不稳定会直接导致体积测量（如肿瘤体积、最大径）产生较大误差，进而影响治疗计划的制定与疗效评估的可信度。
- **研究目标**：提出一种**参数高效**的 2.5D 纵向融合方法，在冻结 SAM2 编码器的前提下，将相邻切片间的上下文信息注入模型，从而在不引入大量可训练参数的情况下有效抑制纵向闪烁。

### 2. 提出的方法论

- **核心思想**：采用 **2.5D 纵向融合**策略——既不逐切片独立处理（2D），也不对整卷进行全量三维建模（3D），而是以 **k 个连续切片构成的窗口（k-slice window）** 作为输入，利用轻量可学习模块在切片维度进行信息融合，获得纵向感知的特征表达。
- **方法名称**：**Z-Adapter**（Z 轴适配器），即沿 CT 的 Z 轴（层间方向）添加适配模块。
- **关键技术细节**：
  1. **冻结主模型**：SAM2 的图像编码器（image encoder）权重保持冻结，不参与梯度更新，充分保留预训练模型的先验能力。
  2. **Depthwise 1D Token Mixing**：在 k-slice 窗口内，将各切片的 token 序列沿切片轴做逐通道的 1D 卷积/混合操作，实现跨切片的特征交互。这种设计的核心优势是：只引入极少量参数（1D 卷积核），即可让每个切片的特征携带相邻切片的信息。
  3. **仅更新少量模块**：训练过程中只更新 **一个小的 Adapter 模块** 和 **掩膜解码器（mask decoder）**，整个编码器保持冻结，整体可训练参数占比非常低。
  4. **边界感知的纵向一致性损失（Boundary-aware Longitudinal Consistency Loss）**：在损失函数层面显式约束相邻切片掩膜之间的一致性，从而抑制纵向闪烁。该损失函数具有**边界感知**特性——在肿瘤边缘区域允许更精细、更锐利的过渡，避免过度平滑导致边缘模糊。
- **算法流程（文字描述）**：
  - 输入 k 张连续 CT 切片 → 经过冻结的 SAM2 编码器提取各切片特征 → Z-Adapter 沿切片轴对 token 做 1D 深度可分离混合 → 得到融合后的纵向感知特征 → 送入（微调的）掩膜解码器输出各切片的分割结果 → 计算分割损失与边界感知纵向一致性损失 → 反向传播更新 Adapter 与解码器参数。

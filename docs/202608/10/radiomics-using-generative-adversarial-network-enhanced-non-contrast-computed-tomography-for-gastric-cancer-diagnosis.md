# 论文总结：使用生成对抗网络增强的非增强计算机断层扫描影像组学用于胃癌诊断

## 📌 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：胃癌诊断中，非增强CT（NCCT）图像组织分辨率有限，难以准确反映肿瘤特征；而增强CT（CECT）虽然诊断效能更好，但存在静脉造影剂过敏反应风险和更高的辐射暴露。
- **研究动机**：在临床实践中，部分患者因肾功能不全、造影剂过敏等原因无法接受增强CT检查，导致诊断信息不足。因此，亟需一种无需造影剂即可获得近似增强CT诊断效能的替代方案。
- **核心意义**：本研究提出一个创新性的辅助诊断框架，通过生成对抗网络（GAN）从NCCT图像合成增强CT（SCECT）图像，并在此基础上进行影像组学分析，从而在**不注射造影剂**的前提下提升胃癌的诊断能力。该框架有望减少对增强CT检查的依赖，为无法耐受造影剂的患者提供更安全、更经济的诊断选择。

## 🧠 方法论：核心思想、关键技术细节与算法流程

- **整体框架**：分为两个阶段——①图像增强阶段（NCCT → SCECT）；②影像组学分析阶段（基于SCECT进行病理预测）。
- **图像配准**：采用**对称归一化（Symmetric Normalization）** 算法对同一患者的NCCT和CECT图像进行配准，确保像素级对应关系，为监督学习提供高质量的“伪标签”数据。
- **生成模型设计**：构建了多种基于**Pix2Pix架构**的变体模型，关键改进包括：
  - 引入**注意力机制**（attention mechanisms），增强模型对胃部病灶区域的关注能力；
  - 设计**复合损失函数**（composite loss function），综合像素级损失与感知级损失，提升生成图像的质量与结构保真度。
- **模型选择流程**：通过消融实验（ablation experiments），使用定量指标——**平均绝对误差（MAE）、均方误差（MSE）、峰值信噪比（PSNR）、结构相似性指数（SSIM）**——确定最优生成模型配置。
- **影像组学分析**：对生成的SCECT图像提取影像组学特征，建立分类模型，分别预测：
  - 组织学分级（低级别/高级别）
  - Lauren分型（弥漫型 vs. 非弥漫型）
  - T分期（T3–T4 vs. 早期）
- **基准对比方法**：最优模型与**Pix2Pix**、**CycleGAN**、**BBDM**（一种扩散模型）进行对比，验证其优越性。

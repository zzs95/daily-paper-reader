## 一、论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：医学多模态大语言模型（Medical MLLMs）近年来快速发展，如 Lingshu、Hulu-Med、LLaVA-Med 等，被广泛应用于医学视觉问答、异常识别、诊断辅助、放射学报告生成等任务。然而，这些模型在临床可靠性方面仍存在显著不足。
- **核心问题**：现有模型在生成放射学报告时经常**遗漏关键异常发现**，甚至生成“过度正常”的报告；这一可靠性问题最终被追溯至**低层视觉感知缺陷**。
- **失败溯源逻辑**：作者采用“任务简化作为诊断探针”的思路，将报告生成逐渐简化为临床诊断、再到病灶属性感知（如位置、大小、密度），发现模型在**最基础的病灶属性理解**上仍然失败。这说明：**高层临床错误（报告/诊断）的根源往往不是语言或推理能力，而是对影像中基本视觉证据的感知不足**。
- **现有 benchmark 的不足**：
  - 2D 基准（如 SLAKE、PMC-VQA、OmniMedVQA）主要覆盖切片级 VQA 或分类式问答；
  - 3D 基准（如 3D-Rad、DeepTumorVQA、CT-SpatialVQA）主要评估体积诊断或病灶相关推理；
  - 缺乏一个**统一、系统、同时覆盖 2D 与 3D 的低层视觉感知评估框架**。
- **整体含义**：论文提出用于系统评估医学 MLLM 感知能力的 **Perception-Bench**（113 万样本），并据此提出感知驱动的模型 **RadSight**，力图证明“可靠的低层视觉感知是临床可靠理解的必要基础”。

### 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）在医学基准测试（如 MedQA、PubMedQA、MedMCQA）上已取得显著成绩，甚至在某些临床问答任务上超越医生基线。这些基准上的高分推动了基于检索增强生成（RAG）的临床决策支持系统的加速部署。
- **核心问题**：现有医学基准将每个问题**孤立评分**，无法衡量模型能否区分**临床上相似但需要不同干预方案**的病例。一个模型可能在某个病人的主诉上回答正确，但当**单个判别性临床参数发生变化**、诊断随之改变时，模型却固守原有诊断——论文将此定义为 **“诊断固着”（Diagnostic Fixation）**。
- **研究空白**：母婴健康领域诊断错误可能威胁两条生命，临床风险最高，但此前**不存在**专门针对母婴/儿科方向的反事实（counterfactual）鲁棒性基准。
- **整体含义**：基础准确率（base accuracy）在临床 AI 中是**系统性误导指标**——全部 8 种模型配置中，基础准确率均高估了鲁棒准确率 16–28 个百分点，说明当前临床 AI 的"高明表现"在很大程度上是脆弱的。

### 2. 方法论

论文贡献两大核心方法：**MamaBench 基准** 和 **EA-RAG 检索管道**。

#### （1）MamaBench 基准

- **问题形式化**：将诊断建模为 f: X → Y。一个**反事实对** (xb, xc) 包含基础案例 xb（真值 yb）和反事实案例 xc——通过**最小扰动**改变判别性参数，使真值变为 yc ≠ yb，同时保留共享的临床背景。
- **诊断固着定义**：模型 f 在基础案例上正确（f(xb) = yb），但在反事实案例上仍然输出 yb（f(xc) = yb），即为诊断固着。该现象与心理学中的**Einstellung（定势）效应** 类比。
- **数据构建**：由三位临床医学专家（产科、妇科、儿科）以**第一人称患者叙述**格式撰写，每对反事实案例通过五类扰动构建：**症状替换、严重程度升级、风险因素修改、时间偏移、合并症引入**。

#### （2）EA-RAG（Evidence-Anchored RAG）

针对标准 RAG 的 **“检索停滞”（retrieval stagnation）** 问题——基础案例与反事实案例的查询嵌入相似度高达约 0.94，导致检索到的上下文几乎相同。EA-RAG 将其替换为**证据覆盖率目标**，分三个阶段，全部在推理时运行，无需微调：

- **Stage 1：证据提取（Evidence Extraction）**——用结构化 LLM 调用（GPT-5.4-nano, T=0）解析患者叙述，提取**类型化临床参数**（E_q）：患者人口学特征、主诉及严重程度标记、风险因素、禁忌症、管理相关特征等。空字段也被视为有用信息。
- **Stage 2：两遍检索与覆盖率审计（Two-Pass Retrieval with Coverage Auditing）**：
  - Pass 1：用 text-embedding-3-large（d=3072）做余弦相似度 top-k（k=5）检索；
  - 覆盖率审计：对每个证据元素 e_j 计算与当前检索集的最高余弦相似度，低于阈值 θ=0.6 的进入 **缺口集** G（gap set）；
  - Pass 2：为每个缺口元素生成**对比性子查询**（"How does e_j change the management of condition X?"），补充检索，去重（δ=0.82）后合并，最终不超过 k+3=8 个块。
- **Stage 3：基于分类学的生成脚手架（Taxonomy-Grounded Generation）**——基于 113 个基线失败案例分析得出错误分类学，为生成器提供针对性指令而非通用 CoT 提示：
  - 错过关键信息（48.7%）→ "分析所有临床参数"
  - 思考不足（31.9%）→ "匹配到具体的严重程度层级"
  - 事实不准确（10.6%）→ "先检查禁忌症"
  - 过度思考（8.8%）→ "果断陈述结论"
  - 脚手架规定**临床推理优先**的层级：先从主诉出发诊断，允许在临床推理与检索冲突时覆盖检索结果，并要求最终诊断验证覆盖所有关键发现。

### 3. 实验设计

- **基准规模**：MamaBench 共 **217 对反事实案例（434 个临床叙述）**，覆盖 **371 种病理**，其中儿科 254 例（58.5%），妇产科 178 例（41.0%），未分类 2 例（0.5%）。
- **评估模型与配置**（共 8 种配置，T=0）：
  - 独立模型（无检索）：GLM-5、Kimi K2.5、Nemotron Super 120B、GPT-5.4、Claude Sonnet 4.6
  - 标准 RAG 基线：GPT-4o（k=2）
  - EA-RAG：GPT-4o（k=5）和 Claude Sonnet 4.6
- **评估指标**：
  - **基础准确率**：Acc_base = (|PP| + |PF|) / N（无论反事实是否做对，只计基础案例正确率）
  - **偏差陷阱率（BTR，主要指标）**：BTR = |PF| / (|PP| + |PF|) × 100%，即基础案例做对但反事实做错的概率
  - **鲁棒准确率**：Acc_rob = |PP| / N（两个案例都做对的概率）
- **评判方式**：LLM-as-judge（Claude Opus 4.5, T=0），对命名法宽松、对改变管理的临床显著修饰语严格。
- **数据隔离**：MamaBench 案例叙述和真值标签**未**注入 RAG/EA-RAG 知识库；检索语料库仅包含教科书指南、WHO 方案等临床参考资料，保证基准数据对检索器完全不可见。
- **消融研究**：基于 GPT-4o 进行**加法消融**，从 k5 基线（top-5 检索，无脚手架、无覆盖率）出发，逐步加入各模块。

### 6. 主要结论与发现

1. **基础准确率具有系统性误导性**：所有模型的鲁棒性差距（Acc_base − Acc_rob）介于 16.2 到 27.6 个百分点之间。GPT-4o 虽有 77.4% 基础准确率，但 BTR 高达 39.9%——约五分之二的"正确"诊断是脆弱的。
2. **标准 RAG 不能解决反事实脆弱性**：GPT-4o 标准 RAG（BTR = 39.9%）与同等能力的独立模型（Kimi K2.5：40.0%）几乎没有差别。"检索停滞"使标准 top-k 检索对反事实扰动完全无感——问题不在于是否检索，而在于检索到了什么。
3. **EA-RAG 显著降低 BTR 且不损害基础准确率**：
   - GPT-4o：BTR 从 39.9% → 35.9%（−4.0 pp）；Claude Sonnet 4.6：从 25.8% → 20.3%（−5.5 pp）；
   - 两者基础准确率仅下降 0.4 pp；
   - 更强的模型获益更大，说明当推理能力充足时，检索质量是主要瓶颈。
4. **模型规模只能缓解不能消除问题**：从 GLM-5（BTR = 50.4%）到 GPT-5.4（BTR = 25.6%）大幅下降，但最强独立模型 Claude Sonnet 4.6 仍在超过 1/4 的"基础胜任"案例上跌倒。
5. **最佳系统仍每 5 例失败 1 例**：Claude + EA-RAG 达到 BTR = 20.3%、Acc_rob = 65.0%，但在部署场景中仍会在约 20% 的诊断模糊案例中遗漏判别性临床参数——这确认了反事实鲁棒性仍是开放难题。
6. **消融揭示模块互补性**：仅覆盖率审计而无后续填补与引导，效果为零（BTR 不变）；脚手架单独带来最大单模块收益（BTR −1.4 pp）；完整流水线优于各部分之和（+2.1 pp BTR 降幅），说明脚手架"教会模型如何推理"与覆盖率检索"确保模型有证据可推理"是互补的。

### 7. 优点

- **填补真实空白**：这是**第一个**面向母婴/儿科健康领域的反事实诊断基准，且全部案例由临床专家**逐例撰写**，而非从既有数据集中转换或由 LLM 流水线生成，内容质量与临床真实性更高。
- **新颖的评估指标**：**BTR 作为条件概率**（给定基础案例成功时反事实失败的概率）比简单的配对准确率更精准地刻画了"诊断固着"这一特定失败模式。
- **方法设计精妙且实用**：EA-RAG 完全在**推理时运行**，无需微调，可即插即用地与任意基础模型搭配；结构化失败分类学驱动的脚手架比通用 CoT 提示更有针对性；失败回退机制（提取失败则退化为单遍检索）保证了不会低于基线。
- **清晰的消融验证**：将"检测证据缺口"与"填补证据缺口"分离，证明单独审计不足、必须配合子查询填补与脚手架引导，因果链条清晰。
- **数据分离严谨**：基准数据与检索语料严格隔离，避免了数据泄漏导致的"假成功"。
- **诚实的负面结果**：主动报告"vanilla RAG 无益"及"最佳系统仍有 20% BTR"，增强了论文的可信度。

# Z-Adapter 论文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：可提示的基础模型（如 SAM2）在医学图像分割中表现出巨大潜力，推动了分割任务的自动化和泛化能力提升。然而，这类模型本质上是为 2D 图像设计的。
- **核心问题**：在 CT 体积数据上逐切片（slice-by-slice）应用 2D 模型，会导致 **纵向闪烁（longitudinal flicker）** 现象——即相邻切片间肿瘤掩膜不稳定、形状突变，进而严重损害体积测量的准确性和下游放疗规划等临床任务的可靠性。
- **研究意义**：如何在**不引入大量训练参数**的前提下，为冻结的 2D 基础模型注入 3D 纵向上下文，同时有效抑制跨切片不一致性，是该论文试图解决的核心矛盾。

## 2. 论文提出的方法论

- **总体思路**：提出 **Z-Adapter**，一种参数高效的 2.5D 纵向融合适配模块，以轻量方式将切片间纵向上下文注入冻结的 SAM2 风格编码器，无需微调整个基础模型。
- **关键设计**：
  - **k-slice 窗口输入**：以连续的 k 个 CT 切片作为输入窗口，为模型提供纵向上下文。
  - **深度 1D token 混合（depthwise 1D token mixing）**：Z-Adapter 沿切片轴（Z 轴）对 token 进行深度可分离的 1D 卷积/混合操作，从而在相邻切片间传递信息，实现 2.5D 融合。
  - **部分微调策略**：训练过程中仅更新小型适配器模块和掩膜解码器的参数，SAM2 风格的编码器保持冻结，大幅降低可训练参数量。
  - **边界感知的纵向一致性损失（boundary-aware longitudinal consistency loss）**：专门设计的一致性正则化项，用于抑制切片间闪烁，同时通过边界感知机制避免对肿瘤边缘的过度平滑，保持分割边界的锐利度。

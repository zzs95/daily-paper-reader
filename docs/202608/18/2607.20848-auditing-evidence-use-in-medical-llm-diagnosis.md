## 1. 论文的核心问题与整体含义

- **研究动机**：医学大语言模型（LLM）常被用作诊断助手，传统评估只看最终诊断是否准确。但准确率无法回答一个关键问题：模型是否*恰当*地使用了病例中的证据？
- **核心问题**：一个模型可能选对诊断，却过度重视临床上弱相关、无关甚至方向误导的证据，也可能忽略关键矛盾信息。准确率会把这种证据使用缺陷掩盖在单一标签之下。
- **整体含义**：论文主张医学 LLM 评估不能只报告诊断准确率，还需要一种“证据使用审计”，即通过受控干预观察模型的诊断偏好是否随证据变化而呈现临床合理的变化模式。

## 2. 方法论

- **核心思想**：将病例分解为证据单元，通过向模型呈现不同证据子集，观察候选诊断的逻辑边界（margin）如何变化，从而挖掘证据间的低级交互，并对交互进行诊断相对的角色归属和临床验证。
- **关键步骤**：
  1. **证据单元表示**：病例被表示为证据集合 \(E = \{e_1, \ldots, e_n\}\)，候选诊断集合为 \(C = \{c_1, \ldots, c_m\}\)。证据包括症状、体征、风险/病史、检验/影像、显式缺失发现等。
  2. **受控干预与评分**：对证据子集 \(T \subseteq E\) 构造提示，要求模型仅返回选项字母；用该字母的下一个 token 对数概率作为候选诊断得分 \(s_T(c_j)\)。
  3. **诊断边际（margin）**：对于审计诊断 \(d\)，定义边际：
     \[
     v_d(T) = s_T(d) - \max_{c_j \neq d} s_T(c_j)
     \]
     该值反映 \(d\) 相对最强竞争者的偏好强度，是交互挖掘的基础。
  4. **诊断相对证据角色**：同一证据可能支持目标诊断、支持竞争诊断、排除目标、构成背景/风险，或在局部临床语境中无关。角色是方向性预期而非硬标签。
  5. **交互挖掘**：通过离散效应公式计算证据集合 \(S\) 的交互效应：
     \[
     I_d(S) = \sum_{T \subseteq S} (-1)^{|S|-|T|} v_d(T)
     \]
     正值为增强目标边际，负值为抑制或偏向竞争者；重点分析低阶（≤3阶）交互。
  6. **自动标签与验证流程**：先根据角色、符号、强度给出临时机制标签（忠实支持、冲突/取消、冗余、背景/历史影响、否定证据误用、无关证据误用等）；候选失败机制需要经过提示词、候选顺序、扰动语义的稳定性检查，并由临床评审做最终裁决。

## 6. 主要结论与发现

- **Finding 1**：准确率不等于证据使用保真度。模型按准确率的排序与按忠实证据强度/冲突强度的排序不一致，说明准确率无法替代证据结构信息。
- **Finding 2**：交互现象常见但多数合理。冲突/取消在 DDXPlus 占交互强度 47.1%，CupCase 45.8%，MedCase 52.2%；误用类强度仅占 1.2%–3.0%。
- **Finding 3**：临床验证后，无效交互集中在“否定/缺失证据误用”和“局部证据过度迁移”。130 项评审中 111 项有效、8 项可疑、11 项无效；5 名评审 Fleiss’ κ=0.82。
- **Finding 4**：目标反事实能区分局部伪影与全局依赖。如移除“肌无力重症”家庭历史提示可使目标边际下降 9.50（Qwen）或翻转排序（BioMistral），而皮肤/皮疹对疝气的影响多为局部不连贯而非全局依赖。
- **Finding 5**：稳定性过滤显著提升候选失败机制精度——从原始队列 0.55 提升到 0.80，假阳性率从 0.20 降至 0.08；随机控制组精度仅 0.10。
- **总体结论**：医学 LLM 的评估应报告“证据使用结构画像”，而非只报告准确率或可疑特征列表；稳定失败模式需要结合证据角色、交互符号、反事实行为和临床审查才能确认。

## 7. 优点

- **行为审计设计**：不依赖模型生成的推理过程，避免 chain-of-thought 不可信问题，只观测受控干预下的偏好变化。
- **诊断相对证据角色**：拒绝“全局相关/无关”的二元标签，能捕捉同一证据在不同诊断中的不同角色。
- **发现与失败分离**：交互挖掘只产生候选机制，失败判定需经过稳定性检查和临床审查，避免将正常鉴别诊断误判为错误。
- **反事实验证**：用“删除/重写可疑证据族”区分局部不连贯与全局依赖，增强了审计结论的可操作性。
- **多维度鲁棒性检查**：提示词变体、候选顺序、删除 vs 中和扰动、证据单元选择敏感性等，使强失败主张建立在稳定证据之上。
- **人工评审规范**：5 名资深医学博士评审、盲审、Fleiss’ κ 报告，提高证据使用判断的可信度。

## 8. 不足与局限

- **依赖构建选择**：结果依赖于证据单元如何切分、候选诊断集如何构建、角色注释如何定义；不同选择可能改变可挖掘的交互。
- **数据集偏差**：DDXPlus 支持结构化角色，CupCase/MedCase 为叙述文本，角色粒度较粗，无法支撑细粒度失败分类。
- **临床审查非随机抽样**：富集样本用于验证审计流程，机制份额和精确率不是基于概率抽样，不能作为总体错误率的估计。
- **模型覆盖有限**：只评估 5 个开源权重模型，不包含更大规模或商用模型，泛化性有限。
- **评分机制偏差**：选项字母对数概率可能受 token 先验和位置影响，虽然采用边际和顺序置换缓解，但并未完全消除。
- **无法捕获潜在推理**：审计是纯行为层面的，不能解释模型内部因果或临床安全性；交互分数是行为信号，不是内部机制证明。
- **阶次上限**：三阶交互是审计目标，但未证明三阶足以涵盖所有重要证据交互，高阶模式可能被遗漏。

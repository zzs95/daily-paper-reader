## 1. 核心问题与研究动机

**研究背景：**
- 医学图像分割是计算机辅助诊断、治疗规划和手术导航的基础，而临床中的医学图像天然伴随丰富的文本信息（放射学报告、诊断描述、临床笔记等），构成多模态临床工作流。
- 既有的视觉-语言模型（VLM）分割方法采用**确定性跨模态对齐**（如余弦相似度、点对点匹配），将视觉与文本特征视为固定点嵌入，忽略了真实临床条件下的两类不确定性：
  - **偶然不确定性（Aleatoric Uncertainty）**：来自图像噪声、模糊边界、文本语义歧义或错误标注，不随数据量增加而减少；
  - **认知不确定性（Epistemic Uncertainty）**：来自有限训练数据、罕见病理、域偏移等，可通过增加数据缓解。
- 在设备异构、采集噪声、标注稀缺的真实临床环境中，确定性对齐在域偏移下表现脆弱，且无法评估每个特征维度的可靠性。

**核心问题：**
> 如何在跨模态医学图像分割中**显式建模并抑制双模态表示的不确定性**，以提升域泛化能力、数据效率与抗扰动鲁棒性？

## 2. 方法论

### 2.1 总体架构

DistMedVL 基于 CLIPSeg，采用**冻结的视觉编码器（ViT-B/16）与文本编码器（Transformer）**，仅训练轻量级 PCM-Adapter 和 CLIPSeg 解码器，整体可训练参数仅 **6.3M**。PCM-Adapter 插入在编码器的第 {2, 4, 6, 8} 层，形成瓶颈式结构：先压缩到共享低维空间、进行概率对齐、再还原到原始维度。

### 2.2 马氏距离对齐模块（MAM）

**核心思想：将文本 token 建模为高斯分布，用马氏距离计算 patch-text 兼容性。**

- 文本语义表示通过线性变换估计每 token 的均值 μt 与方差 σ²t（softplus 保证正定性）；
- 视觉侧由于 patch 密集、直接估计逐 patch 方差噪声大，因此用全局视觉表示估计图像级方差 σ²v；
- 双侧方差融合：σ² = σ²t + sigmoid(θλ) ⊙ σ²v + ε，σ²v 广播到所有文本 token；
- 马氏距离简化为方差加权的欧氏距离（协方差为对角阵）：
  - d²M(Zv, μt) = (1/√D) Σ_d (Zv,d − μt,d)² / σ²_d
  - 方差越大的维度对距离贡献越小，**自动抑制不可靠特征维度**；
- 距离矩阵经温度缩放 softmax 转为兼容性矩阵 A ∈ R^{N×L}，用于加权聚合文本语义生成密集语义先验 S；
- 通过门控机制融合 S 到视觉表示：F̂v = Wo(V + g(V) ⊙ S)，门控输出接近零时自动绕过不可靠的文本先验。

### 2.3 分布流模块（DFM）

**核心思想：全局聚合视觉证据，通过可靠性门控实现视觉引导的文本分布细化。**

- 视觉 patch 语义过于密集，反向逐 token 对齐会产生弥散注意力，因此采用全局聚合策略；
- 计算全局语义均值 μv,g 与 **inter-patch 方差** σ²v,g，衡量各 patch 间的语义一致性；
- 可靠性门控：γ = sigmoid(G(σ²v,g))，对方差高的维度赋予低可靠性权重，抑制不一致的视觉信号；
- 估计模态置信参数 βv、βt，通过残差分布流更新文本语义强度：β*t = βt + MLPf(βv ∥ βt)；
- 最终将 β*t 投影回原特征空间并广播到所有文本 token：F̂t = Ft↓ + MLPr(β*t)。

### 2.4 训练目标

- Lseg = ½(LBCE + LDice)（分割损失）；
- LDistMedVL = λ1·Lseg + λ2·Lcon（λ1 = 0.5，λ2 = 0.1），其中 Lcon 为 CLIP 对比损失。

## 6. 主要结论与发现

1. **最优分割性能**：100% 数据下 DistMedVL 达 87.63% Dice / 92.36% NSD，超越最佳跨模态方法 MedCLIPSeg 1.19% / 1.29%，超越最强单模态方法超 3%。
2. **数据稀缺下优势扩大**：10% 数据时相对最佳方法的优势扩大至 1.85% Dice / 1.75% NSD，验证了概率对齐在认知不确定性升高时更有价值。
3. **域偏移越大提升越显著**：TN3K→PKTN（MMD 最大）中，DistMedVL 取得 2.38% Dice / 4.20% NSD 的显著优势，说明分布对齐能更好地泛化到未见域。
4. **扰动鲁棒性更强**：TN3K 图像扰动下 Dice 仅下降 1.08%（MedCLIPSeg 下降 2.44%），联合扰动下优势更明显，归因于 MAM 的分布级对齐不受查询状态影响，DFM 的可靠性门控可抑制扰动引起的视觉不一致。
5. **消融验证设计合理性**：顺序排列的 MAM→DFM 优于并行配置，验证了级联细化（先获得不确定性精炼的视觉特征再用于全局对齐）的设计动机。
6. **不确定性校准更好**：MC Dropout 不确定性图显示 DistMedVL 将高熵区域集中在边界，抑制了前景/背景中的虚假不确定性。

## 7. 优点

- **轻量高效**：仅 6.3M 可训练参数，编码器完全冻结，训练开销小，适配临床计算资源受限场景；
- **方法创新性强**：将马氏距离引入 VLM 跨模态分割，用方差加权替代确定性匹配，是概率对齐在密集预测任务中的有效延拓；
- **双不确定性建模完整**：MAM 处理特征维度可靠性（兼顾偶然与认知不确定性），DFM 处理模态间语义一致性（可靠性门控），两者互补；
- **实验设计系统**：从数据效率、域泛化、扰动鲁棒性三个角度全面覆盖两类不确定性，对偶发和认知不确定性均有定量分析；
- **公平性控制良好**：不用数据增强、统一配置、统一训练协议，性能差异可归因于模型架构；
- **临床可解释性**：不确定性图的可视化分析表明模型对边界的校准更精确，对临床决策更有参考价值。

## 8. 不足与局限

- **训练数据多样性有限**：5 个训练数据集覆盖 4 种模态，但缺少 MRI、CT 等更广泛模态，可能限制结论的普适性；
- **对比基准不够全面**：扰动实验仅与 MedCLIPSeg 对比（尽管该方法是概率对齐的强基线），缺少与 VLSM-Adapter、CausalCLIPSeg 等最新方法的扰动对比；亦未与 ProbVLM、PCME 等概率嵌入方法对比；
- **文本描述依赖**：TN3K 和 PKTN 的文本由 Qwen2.5 自动生成，非临床真实报告，可能引入合成分布偏移，影响结论在真实临床文本上的适用性；
- **应用限制**：要求输入有配对的文本描述，实际临床中并非所有图像都有报告或注释，未探索仅图像输入的推理模式；
- **资源报告不完整**：未报告训练时长、推理速度等实际效率指标，难以全面评估临床部署成本；
- **统计检验缺失**：未报告多次运行的标准差或显著性检验（如配对 t 检验 / Wilcoxon），部分优势（尤其 0.77%–1.19% 的小差距）的统计显著性存疑；
- **无法定量分离两类不确定性贡献**：虽然分别从认知和偶然两个角度设计了实验，但未定量解析 MAM 与 DFM 各自对哪类不确定性的贡献更大。

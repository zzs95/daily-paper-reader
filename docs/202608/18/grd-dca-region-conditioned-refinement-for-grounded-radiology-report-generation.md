- **背景意义**：在医学影像报告中，无依据的内容不仅误导临床决策，还可能对患者造成实质伤害。因此，让生成模型“言之有据”是从研究走向临床落地的关键一步。

- **核心思想**：提出 **GRD-DCA（区域条件细化）** 机制，在解码过程中动态地将图像区域特征与正在生成的文本片段进行对齐，使文本生成过程受到图像证据的条件约束。

## 2. 论文提出的方法论

### 核心思想
PVRSAP-Net 是一个七阶段流水线，核心创新在于：
1. 在概率空间中对粗先验进行受约束、边缘感知的迭代细化（而非简单平滑或直接丢弃）；
2. 将多尺度窗口注意力以凸融合方式集成，再经残差三维解码输出嵌套区域概率。

### 关键技术与细节

- **多模态标准化**：每个模态在脑掩膜内做 z-score 标准化，裁剪分位数仅从训练集估计。
- **有界边缘感知概率体素细化（BE-PVR）**：
  - 构造六或 26 邻域图，计算模态融合强度 J 和边缘电导 c_ij = exp(-‖x̂_i - x̂_j‖²/κ_x² - |J_i - J_j|²/κ_J²)；
  - 不确定性门 u_i(t)=4p_i(t)(1-p_i(t))，使高置信区域少被修改，0.5 附近体素接受更多修正；
  - 更新公式：q_i^(t+1) = p_i^(t) + β[L_c p^(t)]_i + γ u_i(t)(p̄_i^(t) - p_i^(t))，其中 L_c 为电导加权图拉普拉斯，p̄ 为电导归一化邻域均值；
  - 依次投影到 [0,1] 区间（式 16）和嵌套可行集 C = {p∈[0,1]^{3N}: p^ET ≤ p^TC ≤ p^WT}（式 17），采用三分量 PAV 或近似顺序裁剪；
  - 停止规则：RMS 变化 < δ 或达到最大迭代 R_max；若更新范数连续三次上升则减半步长并返回最佳有限迭代。
- **自适应体素描述符**：拼接强度 x̂_i、纹理特征（局部均值、方差、MAD、梯度范数、LoG、局部共生统计，默认用深度可分离卷积代替显式 GLCM）、上下文池化特征（AvgPool/MaxPool，ρ∈{1,2,4}）、以及细化概率字段及其不确定性变换和梯度。
- **空间注意力金字塔（SAPFormer）**：
  - 多级池化/跨步卷积得到不同尺度特征 F^(ℓ)，在每个三维窗口内计算多头自注意力；
  - 交替使用移位窗口实现跨窗口交互；
  - 各尺度上采样回解码器网格后，通过温度受限 softmax 得到单纯形权重 w_ℓ（非负且和为 1），做凸融合 F_SAP = Σ w_ℓ U_ℓ(Z^(ℓ))；
  - 提供有界输出命题（Proposition 2）：若各分支 Frobenius 范数有界，则融合输出范数不超过最大分支范数。
- **残差三维解码器与嵌套预测**：残差块 ResBlock(X)=X+W_2 φ(Norm(W_1 X))，三个 sigmoid 头输出 ET/TC/WT 概率，再经嵌套投影保证解剖一致性；温度参数在验证集上估计。
- **复合损失**：ℒ_total = λ_D·(区域 Dice 均值) + λ_C·加权交叉熵 + λ_B·边界损失（基于符号距离变换）+ λ_R·Brier 校准项 + λ_H·层次惩罚（ReLU 项）+ λ_W·权重衰减。损失权重在嵌套验证中确定，不允许触碰测试集。
- **训练安全性**：梯度裁剪、非有限损失跳过更新、数据划分哈希、模态顺序校验、测试时保存概率而非仅掩膜。

### 算法流程（文字说明）
- **算法 1（BE-PVR）**：校验输入 → 计算电导 → 初始化嵌套投影 → 逐区域计算不确定性门和邻域均值 → 执行扩散与门控更新 → 区间投影 → 嵌套投影 → 记录审计日志 → 按停止准则迭代。
- **算法 2（SAPFormer）**：校验尺度/窗口 → 构建多尺度特征 → 窗口自注意力（含移位） → 上采样 → 温度 softmax 求单纯形权重 → 凸融合 → 非有限激活时跳过分支并标记。
- **算法 3（泄漏免疫训练与校准推理）**：固定种子、验证 subject 级划分 → 仅用训练数据拟合预处理参数 → 生成并存储细化先验 → 训练主网络 → 验证集选择检查点 → 单独校准集上估计温度和阈值 → 锁定代码与配置 → 一次性测试推理 → 计算指标和审计记录。

## 6. 论文的主要结论与发现

- **受控模拟下**：PVRSAP-Net 的 BE-PVR 将平均 Dice 从原始先验的 0.8551 提升到 0.9091，IoU 从 0.7625 到 0.8382，HD95 从 7.1811 体素降至 1.2316 体素，Brier 分数从 0.0046 降至 0.0040，ECE 从 0.0158 降至 0.0142。
- **区域级**：ET 改善最大（Dice 0.7322→0.8484），WT 几乎不变（0.9531→0.9587），TC 从 0.8801→0.9203；说明细化主要受益于小而复杂区域。
- **消融**：去除边缘电导使 Dice 降至 0.8844；去除层次投影使 Dice 降至 0.8802 且 HD95 升至 5.0622 体素；去除不确定性门对 Dice 无影响（0.9091）。
- **明确边界**：上述结果仅证明合成数据下的内部精化行为，**不代表患者级疗效**；论文未宣称在 BraTS 上超越任何现有方法。

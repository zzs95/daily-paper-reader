## 1. 论文核心问题与研究动机

- **背景**：视觉-语言预训练（VLP）在医学图像分析中成为一种强大的范式，可通过大规模图像-文本对学习视觉表示，无需昂贵的人工专家标注。这一特性对标注成本极高的医学领域尤为重要。
- **核心问题**：将VLP应用于皮肤病学领域时面临两大突出挑战：
  - **数据层面**：从网络爬取的皮肤科图像-文本对存在固有的噪声和稀疏性问题，阻碍了有效的预训练；
  - **知识建模层面**：皮肤病学涉及多维度的复杂医学知识（如形态、分布、病理学等），而这些知识往往隐藏在冗长、非结构化的临床描述中，难以被提取并用于预训练优化。
- **整体含义**：现有方法无法有效利用大规模非结构化皮肤科数据中蕴含的细粒度医学知识，导致模型在下游任务中表现受限。论文旨在通过数据质量增强和知识感知的预训练机制，弥合这一差距。

## 2. 方法论

论文提出一个两阶段皮肤病学VLP框架，核心由两大模块构成：

### 2.1 多智能体数据生成系统（MAGEN, Multi-Agent data GENeration）

用于提升网络爬取数据的质量，核心流程包括：
- **基础模型辅助的标题生成**：利用基础模型（Foundation Model）为图像生成医学知识更丰富、描述更规范的字幕（captioning）；
- **基于检索的验证流程**：通过检索机制对生成的描述进行验证和筛选，确保合成文本与图像内容在医学语义上的一致性；
- **结果产出**：构建了一个包含超过40万对皮肤图像-文本对的大规模增强数据集——Derm1M-AgentAug。

### 2.2 基于本体论的多维度知识增强预训练（O-MAKE, Ontology-based Multi-Aspect Knowledge-Enhanced Pretraining）

用于解决从长文本中学习复杂医学知识的难题，核心思想包括：
- **多维度知识分解**：将冗长、非结构化的文本描述分解为不同的知识维度（aspects），使模型能够分别学习各维度的语义信息；
- **细粒度跨模态对齐**：在全局层面（global level）和图像块层面（patch level）分别进行细粒度的视觉-文本对齐，捕捉局部皮肤病变区域与对应文本描述之间的关联；
- **本体论引导的医学概念关系建模**：借助医学本体论（ontology）显式建模医学概念之间的相互关系（如皮肤病变的鉴别诊断关系、解剖部位关联等），把这些结构化医学知识显式注入预训练过程。

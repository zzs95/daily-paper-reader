# LLaDA MoE v2：扩展混合专家扩散语言模型——中文总结

## 1. 论文的核心问题与整体含义

- **背景**：扩散语言模型（dLLMs）通过迭代去噪生成文本，可作为自回归（AR）语言模型的替代方案；混合专家（MoE）架构则能在不增加单 token 计算量的前提下大幅扩展模型容量。
- **核心问题**：MoE 扩散语言模型的缩放行为仍未被系统刻画。具体包括：
  - 最优 batch size 和学习率如何随训练算力变化；
  - 固定算力应如何在“激活模型计算”与“训练 token 数量”之间分配；
  - 激活模型预算应如何分解为路由稀疏度、专家粒度和共享专家比例。
- **整体意义**：AR 模型的缩放经验不能直接照搬，需要针对 MoE dLLM 目标做校准；论文给出了可操作的缩放规律与设计原则，并用大规模训练加以验证，为这一类模型的扩展奠定了基础。

## 2. 论文提出的方法论

论文采用“小规模缩放实验 → 拟合幂律 → 大规模验证”的三段式流程：

- **优化超参数缩放**：
  - 在模型规模 158M、1B、3.6B，算力 1×10¹⁸ ～ 3×10²⁰ FLOPs 范围内，联合搜索名义 batch size B 和学习率 η；
  - 拟合得到缩放定律：  
    \(B^* = 0.374 \cdot C^{0.3481}\)，\(\eta^* = 64.8 \cdot C^{-0.2447}\)；
  - 与 DeepSeek LLM 的 AR 缩放定律对比，发现 dLLM 的最优 batch 增长更快、学习率衰减更快，在 1×10²⁰ FLOPs 处最优 batch 约为 AR 预测的 3.4 倍。
- **计算分配缩放（IsoFLOP 分析）**：
  - 固定算力预算 10¹⁷ ～ 10²⁰ FLOPs，扫描激活非嵌入 FLOPs/ token（M）与训练 token 数（D），使 C = M·D；
  - 拟合出模型端和数据端前沿：  
    \(M^*(C) = 0.5152 \cdot C^{0.475}\)，\(D^*(C) = 1.9411 \cdot C^{0.525}\)；
  - 数据端指数（0.525）略大于模型端（0.475），表明最优分配呈轻微“数据侧倾斜”。
- **MoE 架构缩放**：
  - 在参考算力点上固定 \(M^*(C)\)，分别扫描三个架构维度：
    - **激活比例 A**：算力越大，越倾向于更稀疏的路由（更低的 A）；
    - **专家粒度 G**：G=8～16 在不同算力下均表现稳健，不是主要缩放方向；
    - **共享专家比例 S**：S=33.3% 在所有算力下均为最优，不同于 AR MoE 常用的固定“单共享专家”或更小比例。
- **大规模模型设计**：
  - 基于上述规律训练 LLaDA MoE v2 30B-A3B：总参数 30B，激活参数 3B；
  - 采用 (A, G, S) = (9.09%, 8, 33.3%)，即 128 个路由专家、top-8 路由、单个宽度为 4 个专家单位的共享专家；
  - 训练五阶段：两阶段 10T token 预训练、2T token 退火、上下文扩展 500B、长上下文退火 1T，总计 23.5T token。
- **SFT 阶段**：基于 7M 条指令数据，仅对响应部分施加掩码去噪目标，训练 3 个 epoch，未使用强化学习（RL）。

## 6. 论文的主要结论与发现

- **优化层面**：AR 缩放规律可作为先验，但需要 dLLM 专门校准；dLLM 在更高

算力预算下，最优 batch size 的增长率显著高于 AR 模型，而学习率衰减更快，表明扩散模型的收敛动态与 AR 不同，直接套用 AR 缩放规则会导致次优，需要针对 dLLM 目标进行重新校准。

- **计算分配层面**：在固定算力下，最优模型端计算（每 token 激活非嵌入 FLOPs）与训练 token 数之间的分配呈现“数据侧倾斜”趋势——随着算力增长，训练数据量的增幅略大于模型容量的增幅。这意味着 MoE dLLM 在大算力下应更倾向于增加训练数据，而非一味扩大激活参数规模，与许多 AR MoE 的“模型侧优先”经验形成对比。
- **架构层面**：
  - 路由稀疏度（激活专家比例）是算力的函数：算力越大，最优激活比例越低，即更大算力应配合更稀疏的路由结构；
  - 专家粒度在 8 到 16 之间表现稳健，不属于关键的缩放维度；
  - 共享专家比例在所有算力下均趋向约 1/3，且其作用随算力增加而增强，这与 AR MoE 中“单共享专家”的常见做法不同，说明扩散 MoE 需要更强共享参数来稳定去噪过程。
- **性能层面**：LLaDA MoE v2 30B-A3B 在 15 项基座基准上平均得分领先 Qwen3 30B-A3B 3.1 分；SFT 后，在 8 项推理和代码基准上以平均 4.0 分优势超越 Qwen3-30B-A3B-Instruct（后者额外使用 RL），在数学与代码任务上表现尤为突出。这表明，即使不采用 RL，基于正确缩放规律训练的 dLLM 也能达到甚至超过同等规模的 AR 模型。
- **缩放效率层面**：通过 compute-controlled 对比（LLaDA MoE v2 7B-A1B 与 LLaDA MoE v2 30B-A3B 使用相同算力训练），论文验证了基于缩放规律设计的大规模模型在给定算力下性能更优，说明其缩放法则确实能够指导实际训练投入的分配。

## 7. 局限性与未来工作

- **缩放规律的适用范围**：实验基于最多 3.6B 总参数的模型拟合幂律，外推至 30B 总参数（激活 3B）虽然得到验证，但更极端的规模（如百亿激活、万亿总参数）仍存在不确定性。
- **架构维度独立性假设**：论文对激活比例、专家粒度和共享专家比例分别做 IsoFLOP 扫描，未系统性地探索三者之间的交互效应。若这些维度存在显著耦合，最优组合可能偏离当前结论。
- **基线比较的公平性**：与 Qwen3 的部分对比成绩直接引用原论文报告值，评估解码参数和提示模板可能不完全一致；另外 Qwen3 的 SFT 基线使用了 RL，而 LLaDA MoE v2 未使用 RL，因此“超越 RL 模型”的结论不能直接归因于预训练方法本身，也可能与 SFT 数据质量和规模差异有关。
- **长上下文与微调阶段**：论文聚焦预训练缩放，上下文扩展和 SFT 阶段的超参数（如 batch、学习率）并没有同等的缩放分析，这部分仍依赖启发式选择。
- **未来方向**：作者建议将缩放规律推广到更多模态、更大的算力区间，并考虑引入联合架构搜索或 RL 后训练；同时，扩散模型的推理成本（多步采样）与 AR 的对比也应纳入资源效率的考量。

## 1. 核心问题与整体含义（研究动机和背景）

医学图像分析领域长期面临一个结构性问题：高质量、大规模、多样化的标注数据难以获取，这使得深度学习模型的泛化能力受限。为此，学界寄希望于**医学基础模型（Foundation Model, FM）**——通过在大量数据上预训练，再用少量标注数据微调到下游任务。然而，现有医学基础模型存在三重局限：

- **专科单一**：大多数模型仅针对病理学（如VIRCHOW、UNI）或放射学（如CT-FM）等单一专科，甚至单一模态，无法联合分析同一患者的跨模态影像。
- **任务类型单一**：模型通常只能处理稀疏任务（分类、回归）或密集任务（分割、检测），难以同时胜任两类任务。
- **维度单一**：医学影像存在多种格式，如2D X光片、gigapixel级全玻片图像（WSI）、3D体数据（CT/MRI）乃至4D多参数MRI，现有模型往往仅支持其中一种。

此外，基础模型的预训练数据通常来自单一或少数机构，缺乏人群多样性。联邦学习有望在不汇集数据的情况下实现多机构协作训练，但大型模型的全量参数交换在通信和算力上不可行。

**本文的核心贡献**是提出 CoM³eT（Co-representation Multidimensional Multitask Medical Transformer），一个统一病理与放射、稀疏与密集预测、二维与高维输入的医学视觉基础模型，并通过**部分微调（partial fine-tuning）**与**联邦学习**实现低资源、隐私保护下的跨机构协作训练。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 总体架构

CoM³eT 基于多任务预训练框架（UMedPT），采用**共享模块 + 任务头**的结构，核心设计如下：

- **视觉骨干（Vision Backbone）**：采用 Swin Transformer V2，接收2D RGB图像块，输出两类特征：
  - **Patch token**：每个输入图像块的向量表示（如512维），是模型的基本单元，用于分类等稀疏任务。
  - **特征金字塔（Feature Pyramid）**：多尺度特征图，保留空间布局，用于分割等密集任务。
- **图像 Transformer（Image Transformer）**：基于 BERT 的编码器结构，建模 patch token 之间的全局交互，为一个多维图像（例如一组切片或WSI中的多个tile）生成聚合的上下文表示。它可处理**非连续和重复位置**（如多参数MRI的多个序列）。
- **金字塔 Transformer（Pyramid Transformer）**：用于密集预测，利用图像Transformer的输出 token，通过自注意力（sigmoid激活）计算各组 patch token 之间的关系矩阵 \( A = \text{sigmoid}(QK^T) \)，并将其注入到视觉骨干的特征金字塔中，形成带全局上下文的特征图，再经解码器生成**hyperpixel token**（空间位置嵌入）。

关键操作可用文字描述为：对每组图像块，先由视觉骨干提取 patch token 和特征金字塔；图像Transformer在所有 patch token 间计算全局上下文；金字塔Transformer将这种全局上下文融入到每个空间位置的特征中，使分割结果不仅依赖局部像素，还依赖整个多维图像的结构信息。

### 2.2 位置编码

采用**对称化的 ALiBi（Attention with Linear Biases）**作为相对位置编码，支持变长序列和长短距离建模。编码距离以“patch token 之间的间隔数量”为单位，而非物理单位，以适应不同尺度的医学影像。对称化设计保证从位置A到B与B到A的注意力偏置相同。

### 2.3 预训练策略

- **多阶段训练**：先在自然图像数据（ImageNet21k、ImageNet-1k、COCO）上预训练，再在自然+医学数据上联合训练。
- **单阶段多任务联合训练**：不同于常见的“先自监督后微调”的串联式训练，CoM³eT 在最后一个预训练阶段同时混合所有数据源和所有监督层级（分类、分割、检测、视觉-语言对齐），避免了顺序训练导致的灾难性遗忘。
- **视觉-语言预训练**：使用 SONAR 作为冻结的文本模型，训练目标为标题生成和标题判别（CoCa启发），判别权重80%、生成权重20%。
- **多任务交替训练**：为节省显存，每个训练步骤只处理一个任务，更新该任务头后立即丢弃其梯度，使显存占用与任务数无关。
- **注意力拓扑增强（Attention Topology Augmentation）**：在多维分类任务中，随机丢弃图像Transformer中的注意力连接（drop rate=0.5），以正则化并防止过拟合。

### 2.4 部分微调与联邦学习

- **部分微调**：冻结视觉骨干，只训练图像Transformer、金字塔Transformer和解码器。可训练参数仅占总参数的约2.5%（97.5%被冻结），且由于骨干被冻结，patch token 可以**缓存**，微调计算成本大幅下降。
- **联邦微调**：基于 Flower 框架实现，各站点本地训练4步后同步一次可训练参数（仅图像Transformer部分），骨干缓存保持在本地。在真实德国大学医院场景中，使用消费级GPU和互联网连接完成训练。

### 2.5 合成基准验证

为隔离验证各组件的作用，设计了两个合成任务：

- **合成分类任务**（基于MNIST）：有序的8张数字图像组，要求模型预测每组中的全局最大值、唯一数字、局部邻居最大值以及是否位于组中间（测试相对位置编码对绝对位置的能力）。
- **合成分割任务**：每组3~8张含几何形状（椭圆、矩形、X形）的图像，任务包括局部上下文分割（分割相邻图像中的椭圆）、全局上下文分割（当X是组内最常见形状时分割所有X）以及提示拷贝分割（根据文本提示跨图像拷贝矩形分割）。

## 6. 主要结论与发现

1. **统一架构可行性**：CoM³eT用单一架构同时支持病理/放射、稀疏/密集、2D/3D/WSI任务，并在UNICORN竞赛中排名第一，平均任务指标0.442，显著优于理论最佳集成（0.357）。
2. **图像Transformer的有效性**：在多维分类任务中，图像Transformer显著提升性能（如MRI肿瘤分类AUC从0.782提升到0.859；WSI癌症复发C-index从0.644提升到0.736）。
3. **金字塔Transformer的必要性**：在3D分割任务中，金字塔Transformer带来显著增益，尤其在病灶分割任务中（乳腺MRI肿瘤分割Dice从25.28%提升到58.62%，超过nnU-Net的33.13%）；但最终体积误差从4.46ml降至2.15ml，优于nnU-Net的4.23ml。
4. **部分微调等效于全量微调**：等价性检验支持两者的性能等价（p_lower<0.001, p_upper=0.008），且部分微调大幅降低算力需求（缓存后几乎零成本）。
5. **联邦学习可达到集中式训练水平**：在真实跨站点场景中，联邦微调与集中式数据池化的性能差异被等价性检验排除（p_lower=0.019, p_upper=0.032），说明在隐私保护下联邦学习是可行的。
6. **单阶段多任务预训练的价值**：挑战了“必须依赖自监督预训练”的主流观点，结构化标签和文本监督可以协同工作。

## 7. 优点

- **架构创新**：用“patch token + 图像Transformer + 金字塔Transformer”统一了多维稀疏与密集任务，避免了为每类任务单独设计模型。
- **实用性强的部分微调**：冻结骨干+缓存patch token使几乎任何机构都能微调，降低了基础模型的准入门槛。
- **灵活的联邦学习配方**：基于部分微调的通信高效方案，可在消费级GPU和互联网环境下部署，具备现实可用性。
- **广泛的预训练覆盖**：60+个任务、多种模态，且引入合成基准进行可解释的组件消融。
- **严谨的统计工具**：使用等价性检验（TOST）、bootstrap置信区间，避免了“无差异”的误导性断言。
- **开源可用**：代码公开在GitHub上。

## 8. 不足与局限

- **预训练数据仍以公开数据为主**：虽然联合了多个医院，但联邦实验仅涉及微调阶段，预训练阶段的数据汇集仍是集中式的，未验证真正的“联邦预训练”。
- **3D分割的粒度限制**：金字塔Transformer在“切片级”上下文上操作，无法逐体素建模，导致小血管等精细结构的分割不完美；作者坦承未优化任务头（如3D卷积头）。
- **位置编码的局限性**：相对位置编码（ALiBi）对长距离绝对位置（如“组中间”）的建模能力有限，合成实验中也体现了这一点，可能影响某些依赖绝对位置的任务。
- **联邦学习的实际挑战**：网络安全、连接超时、数据访问策略等问题在真实部署中仍需大量人工干预，模型本身无法解决。
- **评估偏差风险**：UNICORN竞赛中其他模型并非都能处理所有任务，对比的“理论最佳集成”是基于每个任务最佳模型的组合，但实际中不可能预先知道哪个模型最佳，因此该比较对CoM³eT有利。
- **部分微调在2D任务上略有性能折损**：如超声分割Dice从75.5%（全量）降到71.1%（部分），虽然等价性检验通过，但在某些高精度需求场景下差异可能仍有临床意义。
- **未报告预训练的总算力消耗**，无法评估训练的可复现成本。

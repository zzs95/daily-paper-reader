## 2. 论文提出的方法论

- **核心思想**：提出一种**多模态深度学习框架**，将胸部X光图像与人口统计学元数据（年龄、性别、投照体位）在特征层面进行融合，用于14种胸腔疾病的多标签分类。
- **总体架构**：框架由五大阶段组成：

- **图像分支**：采用在ImageNet-22K上预训练的**ConvNeXt Large**网络作为骨干提取图像高维特征。经过全局平均池化和Dropout(0.3)后，投影成 **512维图像嵌入向量**。

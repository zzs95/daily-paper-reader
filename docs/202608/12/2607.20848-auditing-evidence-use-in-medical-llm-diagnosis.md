## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：医学大语言模型（Medical LLM）的现有评估通常只看“最终诊断是否正确”，即通过完整病例下的多项选择准确率来衡量模型能力。然而，**诊断准确率无法反映模型是否恰当使用了病例证据**——一个模型完全可以在“答案正确”的同时，对临床医生认为薄弱、无关甚至方向性误导的证据赋予过高的权重。
- **深层背景**：临床诊断中的证据不是扁平的特征列表。症状、体征、危险因素、阴性发现（absent findings）和病史在不同鉴别诊断中扮演不同角色；同一发现可能支持一种疾病、支持竞争性疾病、或排除另一种疾病。传统基准将所有这些区分压缩为一个最终标签，丢失了结构信息。
- **研究定位**：本文不是要恢复模型的“内部推理过程”，也不依赖生成的解释或思维链（因为rationale的忠实性已被证明不可靠），而是提出一种**行为审计**——通过受控的证据干预，观察模型的诊断偏好（margin）是否以临床连贯的方式变化。这是一种“反事实/行为测试”风格的评估，而非内省式评估。
- **总体含义**：医学AI评估不应只报告“准确性”，还应报告“证据使用结构”——即模型在多大程度上是基于合理证据支持、合理的鉴别诊断冲突，还是基于捷径式或无关线索做出判断。这一区分对高风险临床应用至关重要。

## 2. 方法论：核心思想、技术细节、算法流程

### 2.1 核心思想

- 将临床病例分解为**证据单元（evidence units）**，在受控的**证据子集干预**下反复对模型进行评分，并挖掘诊断边际（diagnostic margin）中的**低阶交互效应（low-order interactions）**。
- 核心原则：**“交互发现”与“失败认定”分离**——大的或负向交互可能是合理的鉴别诊断（如肺炎证据降低哮喘的边际），不能自动视为错误；只有通过稳健性检查和临床评审的交互才支持“失败”结论。

### 2.2 关键技术细节

- **诊断评分（Diagnostic Scoring）**：
  - 病例表示为证据单元集合 E = {e₁, ..., eₙ} 和候选诊断集合 C = {c₁, ..., cₘ}。
  - 每个提示展示可见证据子集 T 和相同的候选列表，模型只返回选项字母。
  - 评分使用“下一 token 的对数概率” s_T(cⱼ)，而非仅用生成的答案。
  - 对任一被审计诊断 d，定义其在子集 T 下的**边际**为：
    - v_d(T) = s_T(d) − maxⱼ≠d s_T(cⱼ) （即与最接近竞争者的得分差）。
  - 干预方式：主实验中隐藏非目标证据单元；敏感性分析中用“not specified”（未指定）语句替代删除——这点对阴性证据（如“无胸痛”）尤其重要，删除不等于断言其存在。

- **诊断相对的证据角色（Diagnosis-Relative Evidence Roles）**：
  - 每个证据单元相对于被审计诊断被赋予方向性角色：支持性证据、竞争者支持性证据、排除/阴性证据、背景/风险证据、可能无关/临床局部证据。
  - 角色是方向性期望而非硬规则；仅用于解释交互的符号和强度，不自动判定错误。

- **交互挖掘（Interaction Mining）**：
  - 给定价值函数 v_d(T)，对非空集合 S 计算交互效应（Shapley交互指数形式）：
    - I_d(S) = Σ_{T⊆S} (−1)^(|S|−|T|) v_d(T)
  - 对单元素集，即该证据相对空基线的单独效应；对更大集合，衡量单元联合超出个体效应的部分。|S| 为交互阶数，|I_d(S)| 为强度。
  - 主要审计**低阶交互**（尤其三阶），因为可解释且易于临床检查。

- **从交互到审计标签（Pipeline）**：
  - 自动标签是**临时性的（provisional）**，按确定性优先级规则生成。
  - 先检查候选误用条件：①包含显式否定/排除证据的正向交互；②包含临床局部证据但无角色支撑路径的交互。
  - 若非误用，则落入机制标签：竞争者支持证据降低目标边际→“差异冲突/抵消”（differential conflict/cancellation）；目标支持证据间的抑制→“目标冗余”；正向目标支持→“忠实目标证据”；前端、风险、暴露或既往条件→“背景/历史影响”。
  - 候选失败机制：**否定/缺失证据误用**（absent/excluding finding意外增加支持）、**无关证据误用**（临床无关或过于局部的字段强烈影响边际）。
  - 强失败主张仅保留给通过**提示措辞、候选顺序、扰动语义**三重稳健性检查且经临床评审认定无效的交互。

## 6. 主要结论与发现

1. **准确性≠证据使用忠实度**：5个模型在DDXPlus上的准确率排序与忠实目标证据强度/冲突抵消强度的排序不一致；准确率高不一定意味着证据使用合理。
2. **医学交互普遍存在，但多数临床合理**：差异冲突/抵消占DDXPlus交互强度的47.1%、CupCase 45.8%、MedCase 52.2%；忠实/合理支持占其余大部分。三阶交互占高强交互的主导份额（54.4%强度），但低阶交互仍不可忽略。
3. **无效机制集中于证据极性与特异性**：临床评审的130项中，111项有效、8项可疑、11项无效/捷径式。无效项全部集中在否定/缺失证据桶（如“无近期旅行”异常支持过敏性鼻炎、哮喘加重或格林-巴利综合征；皮疹/无脱皮字段支持腹股沟疝或流感等无关诊断）；忠实目标证据几乎总有效，冲突/抵消桶无一被裁定无效。
4. **反事实验证区分局部伪影与全局依赖**：
   - 重症肌无力病例：“疾病名称家族史”是相关但捷径式的置信放大线索（移除后边际下降9.50/6.13，可翻转排名）；
   - 腹股沟疝：皮肤字段形成临床不合理的局部交互，但移除后排名不变→局部不一致而非全局依赖；
   - SLE对照：皮肤证据在系统性症状背景下是临床合理的→同一证据族在不同诊断下角色不同。
5. **稳健性过滤大幅提高失败候选精确率**：原始自动可疑队列（300项）精确率0.55、假阳性率0.20；经提示稳定+顺序稳定+中性化三重过滤后（120项），精确率升至0.80、假阳性率降至0.08；随机对照组精确率仅0.10、假阳性率0.75。中性化显著降低所有模型的可疑信号，但不消除。

## 7. 优点

- **问题定义精准**：将“医学证据是诊断相对的”这一临床常识转化为可计算框架，避免将一切负向交互或大交互误判为失败。
- **“发现与认定分离”的审计范式**：交互挖掘只提出候选机制，失败标签需经过自动规则→稳健性检查→盲法临床评审的完整链条，方法论严谨。
- **行为而非内省**：不依赖模型生成的解释或思维链，避免了rationale不忠实的问题；只观测受控干预下的偏好变化，可操作性强。
- **多维稳健性设计**：提示措辞、候选顺序、删除vs中性化、单元选择策略、随机对照组，系统排除了提示伪影、位置偏差和删除伪影。
- **临床评审质量高**：5位博士级评审员盲法独立评审、Fleiss' κ = 0.82、分歧裁决，且抽样跨机制桶，避免了单一机制主导评审。
- **反事实验证增强了结论的解释力**：区分“局部不一致”与“全局依赖”、直接目标提升与竞争者抑制，避免了过度声称。
- **写作透明**：作者明确标注哪些是描述性结果、哪些是富集样本结论，不夸大总体推断。

## 8. 不足与局限

- **未报告算力细节**：没有GPU型号、数量、推理耗时等资源信息，可复现性受影响。
- **总体估计受限**：临床评审样本为富集抽样，精度/机制占比/过滤值不是总体发生率估算；需要概率抽样和更多模型才能外推。
- **模型覆盖有限**：仅5个开源权重模型（4B–8B），未覆盖更大规模或闭源模型；结论对更大模型、不同训练分布的泛化性未知。
- **交互阶数封顶**：三阶交互为主，但无法证明三阶足够；更高阶交互可能被遗漏。
- **选项字母评分的固有限制**：选项字母的对数概率可能包含 token 先验和位置偏差；边际分析虽缓解但未校准为真实概率。
- **证据单元选择和角色标注依赖人工**：CupCase/MedCase使用提取的叙事句子和粗略标签，无法支持DDXPlus级别的细粒度失败分类；不同单元选择策略下顶层交互重叠率仅约0.5，说明机制层面稳定但具体交互不稳定。
- **不声称临床安全**：审计测量的是提示条件下的偏好，不是潜在推理或临床安全；交互分数是行为信号而非内部因果解释。

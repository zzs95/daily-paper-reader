# RynnBrain 1.1：面向更强大、更泛化的具身基础模型——论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的具身智能模型需要在物理世界中超越简单的视觉识别和语言理解，具备3D结构理解、多视角推理、语言到物理位置的基础能力，并最终支持下游操作策略。然而，当前的具身基础模型（如RynnBrain 1.0）在以下两方面存在不足：
  - 模型的表示和输出与机器人实际操作的对齐不够紧密（如抓取表示不够精确）；
  - 模型作为下游视觉-语言-动作（VLA）策略初始化时的能力迁移效果有待验证。
- **整体含义**：本文提出RynnBrain 1.1，一个从2B到122B-A10B参数规模的新型具身基础模型族，通过引入接触点预测和原生3D基础（3D grounding）两个新任务，将模型表示更直接地与机器人操作对齐；并进一步开发RynnBrain-VLA，使用统一跨本体动作空间，在多个真实机器人平台上实现稳定操控。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 构建一个统一的时空与物理基础训练框架，使模型同时具备具身感知、空间推理、定位和规划能力。
- 将视觉输入（图像、视频、多视角）统一表示为有序帧序列，通过离散化坐标token将语言和空间输出放在同一个自回归框架中预测。
- 在预训练阶段引入接触点预测（中心点+平面旋转角）和3D基础（相机坐标系下的9维参数化3D框）两大新任务，以增强模型对操作相关特征的表示能力。
- 在VLA后训练阶段，设计统一跨本体动作空间（81维，分为臂关节、末端执行器、夹爪、手、躯干、头等语义分组），通过本体特定掩码激活可用维度，实现不同机器人的联合训练。

### 关键技术细节
- **模型架构**：基于Qwen3.5的解码器式视觉-语言架构，包含视觉编码器、视觉-语言投影器和LLM主干。三种规模（2B、9B、122B-A10B）共享同一架构和训练配方。
- **训练配方**：
  - **统一时空表示**：将静态图像（T=1）或视频（T>1）采样为帧序列，附加时间位置信息。
  - **物理接地输出空间**：除文本token外，输出序列包含离散化的边界框、点、轨迹waypoint坐标（[0,1000]整数）。
  - **接触点预测**：表示为一个中心点(p)和平面内角度θ，格式为 `<grasp pose>(x,y),θ</grasp pose>`。数据来源于Grasp-Anything等数据集的渲染和投影。
  - **3D基础**：输入图像、自然语言指令和相机内参，直接预测相机坐标系下的3D框参数（中心位置、尺寸、方向），均以物理单位离散化为token。数据来源于WildDet3D和FoundationPose。
  - **优化**：端到端自回归训练，损失为负对数似然。
- **VLA架构**：采用流匹配框架，LLM骨干本身作为单流扩散变压器（DiT）。输入语言指令、多视角图像、机器人状态、噪声动作块，输出去噪后的动作块。使用KV缓存加速推理。
- **跨本体部署**：三层架构（模型层、控制层、本体层），控制层含30Hz低频率循环和200Hz高频率插值循环。使用实时分块（RTC）技术，每5步触发一次新推理以保证平滑。

## 6. 主要结论与发现

- RynnBrain 1.1在所有规模上均优于此前RynnBrain 1.0，并显著超越其他同等规模的开源/闭源模型，尤其在推理密集型任务（MMSI、MindCube）上。
- **模型缩放带来非均匀收益**：通用认知任务随规模线性增长；推理密集型任务仅在有具身监督的RynnBrain上提升，纯VLM缩放反而下降；定位任务中数据缩放比模型缩放更重要。
- **3D基础有效**：2B和9B版本在SUN RGB-D和WildDet3D-Bench上表现竞争力，接近闭源大型模型。
- **接触点预测能生成任务相关的接触位置**：定性示例表明模型能根据指令选择把手、翻转的杯口等。
- **更强的具身基础模型带来更好的VLA策略**：RynnBrain-VLA在三个任务上平均成功率86.67%，远高于Qwen-Based-VLA的60%。
- **联合多任务多本体训练进一步提升性能**：RynnBrain-VLA Generalist平均成功率91.67%，高于单任务训练的86.67%。
- 统一动作空间和本体掩码有效支持跨本体知识共享。

## 7. 优点

- **方法创新**：
  - 引入接触点预测（紧凑的中心+角度表示）替代传统四角抓取框，更直接对齐动作。
  - 原生3D基础训练，使模型具备显式物理空间理解。
  - 统一动作空间+本体掩码，实现真正的跨本体联合训练。
- **实验全面**：
  - 涵盖2B到122B多尺度，系统性研究缩放规律。
  - 在数十个基准上对比大量SOTA方法，包括闭源商业模型。
  - 真实机器人部署在三种异构平台上，验证实际有效性。
- **性能领先**：122B-A10B在VSI-Bench、MMSI、RefSpatial-Bench上超越所有对比模型。
- **可复现性**：开源模型权重、网页demo和HuggingFace/ModelScope集合。

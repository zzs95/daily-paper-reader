## 论文中文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

放射组学（radiomics）特征易受研究方案、采集参数、分割等“外部”因素影响，这些已被广泛研究。然而，特征选择（FS）算法这一“内部”因素对放射组学签名稳定性和预测性能的影响却很少被关注。在样本量小、类别不平衡的临床场景中，FS算法的稳定性（即数据轻微扰动下所选特征的一致性）至关重要，不稳定的选择会导致不可靠的签名和过乐观的交叉验证性能。该研究旨在探索自监督深度稀疏自编码器（autoencoder, AE）作为放射组学特征选择方法，并与经典FS方法系统比较稳定性、性能及计算成本。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：利用自监督深度稀疏自编码器在无标签下学习数据重构，通过比较多数类与少数类样本的重构误差差异（delta）来评估特征重要性，实现特征选择。这种方法无需类别标签（自监督），能建模特征间非线性关系，且对类别不平衡鲁棒。
- **三种AE变体**：
  - **singleAE**：单个8层稀疏自编码器（输入/输出层89个神经元，编码路径50→30→20→10，解码镜像）。训练时使用所有多数类样本重构，验证集由所有少数类样本+等量随机多数类样本组成。通过计算验证集上两类样本每个特征平均重构误差（MRE）之差δ = MRE_多数 - MRE_少数，取绝对值大的特征为重要。
  - **ensembleAE**：集成100个独立训练的singleAE，每个使用不同训练/验证划分，最后平均δ向量得到更稳健的排名。
  - **bayesianAE**：在singleAE每个隐藏层后使用MC Dropout（丢弃概率0.5），推理时保留dropout，经过100次蒙特卡洛前向传播得到δ的分布，平均后作为最终δ。以此近似集成的不确定性量化，但只需训练单个模型。
- **损失函数**：结合重构误差（MSE）和稀疏惩罚（嵌入层L1正则化）：  
  \( C = \frac{1}{N} \sum_i ( \|x_i - \hat{x}_i\|_2^2 + \lambda \|h_i\|_1 ) \)
- **特征排名**：根据δ值从大到小排序所有特征，得到全局排名。

### 3. 实验设计：数据集、基准、对比方法

- **数据集**：100例极低风险前列腺癌主动监测患者，使用多参数MRI（T2w、ADC、DCE减影图），提取288个原始3D放射组学特征（无滤波），经去低方差、去相关后保留89个特征。终点为Gleason评分升级（GS>3+3）的二分类。
- **基准**：随机FS算法作为参考基线。
- **对比方法（经典FS）**：
  - 过滤方法：Wilcoxon秩和检验(WLCX)、互信息最大化(MIM)、最小冗余最大相关性(MRMR)
  - 嵌入方法：LASSO
  - 包装方法（基于贪婪后向选择）：SBS+逻辑回归(LR)、SBS+线性SVM(L-SVM)、SBS+随机森林(RF)、SBS+多层感知机(MLP)
- **评估指标**：
  - **全局稳定性**：Spearman秩相关系数（衡量整体排名一致性）
  - **局部稳定性**：Dice、Jaccard、Kuncheva重叠指数、最大加权匹配(MWM)代价（在top-k=5,10,15,20,25特征子集上）
  - **预测性能**：微平均AUC（使用逻辑回归分类器）
  - **计算成本**：执行时间（秒）和峰值内存（MiB）

### 6. 论文的主要结论与发现

1. **经典方法中**：包装方法（SBS系列）稳定性最差，过滤方法WLCX局部稳定性最高（top-5 Kuncheva指数0.39）且性能较好（AUC=0.59），但全局稳定性中等（Spearman=0.53）。LASSO全局稳定性最高（0.94）但局部稳定性很低（0.23），原因是大量系数被收缩为零导致排名虚假一致。
2. **AE变体之间**：bayesianAE全局稳定性最高（Spearman=0.72），高于ensembleAE（0.65）和singleAE（0.53）。局部稳定性（top-5）三者相近（Kuncheva约0.36-0.38），且与WLCX无显著差异。bayesianAE计算效率远高于ensembleAE（快95倍、省84%内存）。
3. **跨家族对比**：AE变体（尤其是bayesianAE）在全局和局部稳定性上优于或持平于最佳经典方法WLCX，且预测性能无显著差异（AUC 0.58 vs 0.59, p=0.18）。
4. **签名相关性**：不同FS方法选出的顶部特征重叠很少，甚至最佳性能方法之间（WLCX与bayesianAE）特征相关性也较低（Pearson=0.41），说明方法选择会显著影响签名构成。
5. **实用性建议**：在小样本、类别不平衡、无外部验证时，推荐使用bayesianAE或WLCX进行稳健特征选择；不应单独依赖全局稳定性指标；稳定性分析应纳入常规放射组学工作流。

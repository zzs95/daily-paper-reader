# 离散扩散语言模型用于交互式放射报告起草：详细总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**: 当前医学基础模型几乎全部采用自回归（AR）生成范式（逐词从左到右生成）。离散扩散语言模型是一种新兴替代方案，通过双向去噪固定长度的令牌画布来生成序列，已在通用文本上达到与自回归模型竞争的水平。然而，其在医学领域的可行性、准确性以及能否提供临床工作流中独特的交互式起草能力，尚未得到系统测试。
- **整体含义**: 本文旨在验证离散扩散语言模型作为医学基础模型的可行性，并利用其固有的双向生成特性实现“任意顺序填充”（any-order infill）——放射科医生可以固定报告的部分片段，让模型填充片段之间的文本。这种能力是自回归模型无法天然拥有的。研究通过匹配扩散模型与其同族自回归模型（相同参数量、视觉编码器、LoRA配方）进行公平对比，为医学文本生成领域提供了非自回归范式的新选择。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
将离散扩散语言模型（DiffusionGemma-26B）应用于医学视觉问答（VQA）和放射报告生成与填充任务。通过双向去噪生成过程，实现任意位置的文本填充（infill），而无需重新训练模型。

### 关键技术细节
1. **匹配骨干网络**:
   - 扩散模型: DiffusionGemma-26B (25.2B参数，3.8B活跃参数，MoE架构)
   - 自回归对比模型: Gemma-4-26B (相同家族、相同参数量、相同视觉编码器 SigLIP 系列，约280个图像令牌)
   - 两者共享除生成范式外的所有组件：视觉编码器冻结，LoRA适配（rank=64，α=128，适配注意力与共享MLP投影），优化器参数因范式而异（扩散用AdamW β=(0.9,0.95)，AR用β=(0.9,0.999)）

2. **图像条件适应**:
   - 两种范式均以图像和提示为条件，仅对目标文本（报告或答案）进行监督，目标字符串相同。
   - 扩散模型使用均匀状态离散扩散目标（dLLM objective）：随机替换部分目标令牌为均匀采样的随机令牌（非[MASK]），训练模型恢复它们。
   - 自回归模型使用标准的下一个令牌交叉熵损失。

3. **任意顺序填充（Infill）**:
   - 定义固定位置集合 \(F\) 和自由位置集合 \(\bar{F}\)，填充条件分布为 \(x_{\bar{F}} \sim p_\theta(x_{\bar{F}} | x_F = a, c)\)。
   - 扩散模型无需重新训练：在每一步去噪时，强制固定位置的令牌保持不变（在更新前后均重新施加），自由位置从双向上下文（左右两侧的固定文本）中获得信息。
   - 自回归模型因从左到右分解，无法利用右侧固定文本，因此不具备真正意义上的双向填充能力。即使将右侧文本放入提示中，也无法改变其单向条件化的本质。

## 3. 实验设计：数据集、基准与对比方法

### 数据集

- **填充评估**: MIMIC-CXR (249份报告，每个报告掩码一个完整句子进行填充)

### 评估基准
- 医学VQA: 使用LLM作为评判（Claude Sonnet 4.6）进行语义等价性打分（二元判决），避免精确匹配对冗余表述的惩罚。

- 任意顺序填充: 在MIMIC-CXR上，比较双向条件与仅左条件下的令牌F1和LLM评判准确率。

### 对比方法

2. 前沿VLM对比: Gemini-3.5-Flash、GPT-4.1-mini、Claude-Sonnet-4.6（均为零样本，单次前向传播）。
3. 填充实验中：扩散模型 vs. 自回归模型（提示包含右侧上下文）。

## 6. 论文的主要结论与发现

1. **扩散模型匹配或超越自回归模型**: 在医学VQA三项数据集上，微调后的扩散模型在LLM评判准确率上均不低于其AR同胞（SLAKE上显著更高 +0.046，p=0.026），零样本时也全部超越AR。
2. **推理速度显著更快**: 扩散模型生成256令牌比AR快3.5–4.4倍，吞吐量高5.7–7.1倍。
3. **任意顺序填充能力是扩散模型独有优势**: 在MIMIC-CXR填充实验中，扩散模型利用右侧上下文使token-F1提升+0.109（p<1e-10），LLM评判提升+0.129（p=2e-5）；AR即使提示中给出右侧上下文，也无法获得显著提升（+0.031 token-F1，p=0.08）。模型×上下文交互效应显著（+0.078 token-F1，p=2e-4；+0.145 LLM评判，p=3e-4），扩散模型受益程度是AR的3.5倍以上。
4. **微调后的扩散模型（3.8B活跃参数）与前沿VLM竞争力相当**: 在SLAKE上表现最佳（0.863），超过Gemini-3.5-Flash（0.751）等；在VQA-RAD和VQA-Med上略低于Gemini，但超越GPT-4.1-mini和Claude-Sonnet-4.6（注意评判模型本身也是Claude Sonnet 4.6，可能存在偏差但结果在噪声范围内）。
5. **释放代码与微调检查点**: 代码和模型权重已开源。

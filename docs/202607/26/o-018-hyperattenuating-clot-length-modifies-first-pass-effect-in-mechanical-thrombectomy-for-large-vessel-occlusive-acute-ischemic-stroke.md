## 速览
**TLDR**：非对比CT（NCCT）上约2/3的大血管闭塞表现为高密度血栓且可测量长度。本研究分析接受机械取栓的急性缺血性卒中患者，发现较长的高密度血栓长度与较低的首次通过效应（单次取栓完全再通）独立相关，阈值约为11mm。该指标可辅助术前预测取栓成功率，优化治疗决策。 \
**Motivation**：探索术前NCCT上高密度血栓长度能否预测机械取栓的首次通过成功率，以指导患者分层。 \
**Method**：回顾性分析大血管闭塞患者，在NCCT上测量高密度血栓长度，采用多变量回归评估其与首次通过效应（FPE）的关系。 \
**Result**：较长血栓长度（≥11mm）与显著降低的FPE率相关（调整后OR=0.48，p<0.001），且独立于年龄、NIHSS评分等因素。 \
**Conclusion**：NCCT上的高密度血栓长度是预测首次通过效应的简便、快捷指标，可用于临床决策。

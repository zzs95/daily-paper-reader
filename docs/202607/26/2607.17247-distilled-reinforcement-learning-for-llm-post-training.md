### 1. 论文核心问题与整体含义（研究动机和背景）
- **核心问题**：大型语言模型（LLM）后训练中，强化学习（RL）和在线策略蒸馏（OPD）各有局限。RL 依赖粗粒度的结果级奖励，难以进行细粒度信用分配，且无法有效获取教师模型的新知识；OPD 通过无条件 KL 散度模仿教师，面临教师-学生分布不匹配时性能下降、过早收敛等问题。
- **研究动机**：现有方法无法有效结合 RL 的探索优势和教师的细粒度指导，尤其在跨模型家族蒸馏（cross-family distillation）时，OPD 效果显著退化。因此，需要一种统一框架，既能利用教师的知识，又不破坏 RL 的优化信号。
- **整体含义**：本文提出 Distilled Reinforcement Learning（Distilled RL），将教师监督直接融入 RL 梯度，实现选择性的、细粒度的知识迁移，同时保持 RL 的奖励驱动优化。

### 2. 论文提出的方法论
- **核心思想**：在 RL 策略梯度中引入教师对每个token的偏好，通过重要性加权重新分配学习信号，避免无条件模仿。
- **关键技术细节**：
  - **反向重要性采样（Reverse Importance Sampling）**：计算教师策略与旧学生策略的token级比率 ρ = π_teacher / π_θ_old，并裁剪到 [1/ϵ_ρ, ϵ_ρ] 以防止梯度不稳定。
  - **负样本重置（Negative Sample Reset）**：仅对优势为正（A>0）的响应应用教师加权；对于负优势响应，权重置为1，从而避免在学生错误轨迹上强制模仿教师（否则会惩罚教师偏好的token）。
  - **序列级几何归一化（Sequence-Level Geometric Normalization）**：对每个响应的裁剪比率进行几何均值归一化，使得整个序列的几何均值为1，消除教师概率系统性偏低导致的全局抑制，同时保留token间的相对偏好。
- **公式与算法流程**：
  - 目标函数如论文式(3)：J(θ) = E[ (1/G) Σ_i (1/|o_i|) Σ_t min( r_i,t·w_i,t·A_i, clip(r_i,t, 1-ϵ_low, 1+ϵ_high) · w_i,t·A_i ) ]。
  - 其中 w_i,t 由 ρ 经过裁剪、几何归一化后得到，且对负样本设为1。

### 6. 论文的主要结论与发现
- Distilled RL 在所有学生模型和基准上一致优于 RL、OPD 和 OPD+RL，平均 Pass@1 提升显著（如 DSQW-1.5B 上提升 4.73 分 vs OPD）。

### 7. 优点
- **方法创新性**：将教师知识直接嵌入 RL 梯度而非作为独立的 KL 项，避免了无条件模仿的缺陷，设计简洁且有效。
- **轻量高效**：不要求教师模型额外生成样本，仅需计算 token 概率；训练时只对学生轨迹进行评估，计算开销低。
- **可解释性**：通过熵控制的案例直观展示了知识迁移过程。
- **鲁棒性**：在跨族蒸馏这种困难设定下仍显著优于现有方法，表明其对分布不匹配的容忍度高。

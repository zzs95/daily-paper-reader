# 基于解剖与功能感知分层适配器的超声心动图报告生成视觉语言模型

## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：超声心动图报告需要从多个视频视图（如心尖四腔、二腔等）中综合提取解剖结构（如心室壁厚度、瓣膜形态）和功能状态（如射血分数、舒张功能）信息，生成一份完整的“研究级别”报告。现有医学视觉-语言模型（VLM）主要面向单张静态图像或单视图视频，难以有效融合多视图、多模态的时空信息，且缺乏对解剖与功能特征的显式建模。
- **核心问题**：如何利用视觉-语言模型同时建模超声心动图视频中的解剖与功能信息，并生成连贯、准确的长文本报告。
- **研究意义**：该工作探索了多视图医学视频报告生成的新范式，有望减轻医生负担、提高报告一致性，并推动医学影像自动分析在临床场景的应用。

## 2. 方法论
- **核心思想**：提出解剖与功能感知分层适配器（AFHA），采用“分而治之”策略，先分别从多视图视频中提取解剖与功能特征，再通过分层适配模块进行融合，最终输入语言模型生成报告。该设计强调对医学领域特有属性的显式建模，避免了传统方法中将所有视觉特征混为一谈的缺陷。
- **关键技术细节**：
  - **分层视觉提取器**：使用两个独立的编码器分支。解剖分支关注静态结构（如心室轮廓、心肌厚度），功能分支关注动态变化（如室壁运动、瓣膜开闭）。每个分支对多视图视频帧进行时序聚合。
  - **适配模块**：采用分层注意力机制，将解剖与功能特征分别映射到与语言模型可兼容的嵌入空间，而后通过交叉注意力融合成多视图全局表示。适配器参数轻量，以保持预训练语言模型的参数高效微调。
  - **生成过程**：融合后的视觉表示作为前缀（prefix）输入预训练的文本生成模型（如GPT-2或类似架构），以因果语言建模方式预测报告文本。训练时采用交叉熵损失优化。
- **公式/算法流程（文字说明）**：输入多视图视频 → 帧采样 → 解剖编码器输出解剖特征序列，功能编码器输出功能特征序列 → 分别经线性投影及位置编码 → 分层适配器通过自注意力与交叉注意力生成融合视觉token → 语言模型以这些token为前缀逐步生成报告单词。

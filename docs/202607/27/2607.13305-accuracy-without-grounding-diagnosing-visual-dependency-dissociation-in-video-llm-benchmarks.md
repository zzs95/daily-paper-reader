## 论文详细总结（自动生成）

### 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：视频大语言模型（Video LLMs）在基准测试中的准确率常被视为视觉理解的直接证据，但模型可能依赖语言先验（language priors）而非真正视觉推理，导致“没有依据的准确率”（Accuracy Without Grounding）。需要诊断基准测试是否真正测量了视觉依赖，还是仅测量了语言模式利用。
- **背景**：现有基准（如MVBench、Video-MME、EgoSchema）的领先指标驱动着架构选择和部署决策。然而，已有研究（如VQA-CP、TVBench）发现视觉问答中存在语言可解的问题，但未量化和分离准确率与视觉依赖之间的关系。本文首次通过统计检验证明二者是可分离的轴。

### 方法论

- **核心思想**：提出**视觉依赖解离（Visual Dependency Gap, VDG）**，即每个问题在原始视频与黑屏条件下的正确率差异，量化模型对视觉信息的真实依赖程度。VDG > 0 表示视觉有帮助，=0 表示语言先验足够，<0 表示视觉干扰。
- **关键技术细节**：
  - **VDG定义**：VDG(q) = 1[correct(original)] - 1[correct(black)] ∈ {-1,0,+1}。聚合VDG = Acc_orig - Acc_black。
  - **假设检验**：采用配对McNemar检验，分别在原始视频和黑屏条件下比较两个模型的正确率。若两个模型在原始视频上有显著差异但在黑屏上无差异，则证明准确率和视觉依赖可分离。
  - **诊断阶梯**：通过四种条件（黑屏、单帧、打乱帧、原始视频）分解VDG为空间、多样性、时间三个成分：Δ_spatial = Acc_single - Acc_black；Δ_diversity = Acc_shuffled - Acc_single；Δ_temporal = Acc_orig - Acc_shuffled；且VDG = Δ_spatial + Δ_diversity + Δ_temporal。
  - **压缩鲁棒性实验**：使用H.264编码，CRF值从18到38（近无损到重度压缩），分析压缩对准确率的影响，并验证聚合准确率掩盖了双向答案翻转。
  - **FPS消融**：从0.5到24 FPS，证明时间推理VDG与帧率无关，排除稀疏采样假象。
- **算法流程（文字说明）**：
  1. 对每个问题，用原始视频和替换为黑屏的视频分别运行模型，记录正确率。
  2. 计算每个问题的VDG，然后按任务类别或模型聚合。
  3. 对模型对进行McNemar检验，检测原始和黑屏条件下的差异显著性。
  4. 对部分模型执行诊断阶梯：生成黑屏、单帧、打乱帧、原始视频四种条件，计算三个Δ成分。
  5. 对视频进行CRF压缩，评估不同质量下的准确率变化，并分析翻转问题和VDG的关系。
  6. 进行FPS消融，验证时间推理的VDG是否随帧率变化。

### 主要结论与发现

1. **准确率与视觉依赖可分离**：通过McNemar检验，InternVL2-8B在原始视频上显著优于Qwen2-VL-7B，但在黑屏条件下无差异，证明两者是独立能力轴。
2. **任务类型VDG谱系稳定**：属性感知VDG最高（~0.41），时间推理最低（~0.06），此排序在20个模型、三个基准上一致，跨基准标签预测7/7正确。
3. **时间顺序贡献近乎为零**：在16个开源模型上，Δtemporal均小于0.08，视觉依赖主要来自帧多样性（Δdiversity），而非时间顺序。
4. **压缩“鲁棒性”是假象**：聚合准确率随压缩不变，但隐藏了双向答案翻转，且压缩敏感问题更多是VDG=+1的问题，统计显著。
5. **生成退化**：Qwen3-VL相比Qwen2.5-VL在VDG上全面退化（8B仅为0.107 vs 0.297），原因是Δdiversity几乎为零（0.034 vs 0.147），而准确率上看不出明显落后。
6. **API模型VDG范围广**：从0.025（Nemotron）到0.315（Gemini），表明专有模型未必更视觉依赖。
7. **低VDG任务应被标记**：时间推理等任务可主要靠语言先验解决，设计新基准时应优先增强视觉必要性。

### 优点

- **创新诊断工具**：VDG简单有效，直接量化每个问题的视觉依赖，已被证明可分离准确率和视觉理解。
- **统计严谨**：使用配对McNemar检验，提供正式统计证据，而非仅描述性比较。
- **分解能力**：诊断阶梯将视觉贡献分解为空间、多样性、时间成分，揭示当前模型几乎不使用时间顺序，为架构改进提供方向。
- **跨基准泛化**：从Video-MME导出的任务类别VDG排序可预测MVBench和EgoSchema，且零视频源重叠验证了稳健性。
- **细致实验设计**：包含FPS消融、压缩分析、量化比较、API模型扩展，控制多种潜在混淆。
- **开源代码和注释**：提供完整代码库，可复现所有结果。

### 不足与局限

- **仅涵盖多项选择格式**：未评估开放生成任务，VDG在此类任务上的适用性未知。
- **4-bit量化模型结论受限**：大于26B参数的模型使用4-bit量化，量化可能退化视觉通路，论文明确将规模结论限定在bf16模型。
- **诊断阶梯仅用0.25 FPS**：虽然FPS消融覆盖了更高帧率，但阶梯本身未在高帧率下验证，可能低估时间贡献上限。
- **基准覆盖有限**：仅测试三个基准，尽管跨基准泛化良好，但扩展到更多样化基准（如长视频、需要精确时间定位的）仍需验证。
- **计算成本较高**：完整审计需要每个模型在多个条件下推断，对研究者资源有一定要求。
- **未对比其他去偏方法**：论文仅诊断问题，未提出修正方法（如重新设计问题、对抗训练等），对如何构建更视觉依赖的基准仅提供启发式建议。
- **内部信度虽高但跨模型问题级别一致性低**：仅10.3%问题被所有模型视为纯视觉，说明模型间视觉依赖认知差异大。

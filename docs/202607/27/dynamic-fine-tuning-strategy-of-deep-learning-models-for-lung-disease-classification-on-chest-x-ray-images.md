## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：肺部疾病是全球主要致死原因，尤其在发展中国家医疗资源有限。胸部X光（CXR）是广泛使用且成本效益高的筛查手段，但准确解读需要专业知识，且存在读片者差异和工作负荷大的问题。深度卷积神经网络（CNN）在医学图像分析中表现出潜力，但医学数据集通常较小，因此常采用ImageNet预训练模型进行迁移学习。
- **核心问题**：现有微调策略大多采用固定的两阶段范式（先冻结骨干网络训练分类头，再解冻所有层联合训练）。这种方法存在两个关键缺陷：①冻结骨干网络会限制高层特征对胸部X光特定放射学模式的适应；②一次性解冻所有层可能导致优化不稳定和灾难性遗忘，尤其在真实世界的不平衡数据集上。因此，需要一种更自适应、更稳定的微调策略来应对领域偏移和数据不平衡。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：提出一种**验证集驱动的动态微调策略**，根据验证集收敛信号自适应地解冻骨干网络层，而非依赖预定义训练轮数。通过将适应的时间与深度与泛化行为耦合，允许高层特征先适应目标领域，同时保留低层通用表示，减轻灾难性遗忘并提高训练稳定性。
- **关键技术细节**（用文字说明流程）：
    1. 将骨干网络参数按层顺序分为L个组（浅层到深层），初始全部冻结，仅训练分类头。
    2. 每次训练一个epoch后，计算验证集损失。若验证损失连续p个epoch未改善（即收敛平台），则解冻最深层的k个组（逐步增加可训练层数），同时将学习率按固定比例衰减（η ← η(1-0.1)），并将模型参数恢复到验证损失最低的检查点。
    3. 批量归一化层的运行均值和方差在整个训练过程中保持固定，以稳定优化。
    4. 训练停止条件是所有骨干组都已解冻或达到最大epoch数。

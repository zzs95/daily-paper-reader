*   **核心思想**：系统性地探究不同测试时缩放策略在医学领域各种模型和任务上的表现，并识别领域特有的瓶颈。作者提出，通用的“一个策略打天下”的方法在医学领域是失效的。

#### 6. 主要结论与发现

1.  **“更长推理”并非万能药**：
    *   **简单任务**：冗长的顺序缩放有害（模型会“想太多”而偏离正确答案）。**并行缩放**（通过多数投票）效率更高、性能更好。
    *   **困难任务（如MedXpertQA）**：**顺序缩放**（延长思维链）或**增加预算**（单一长链）是必要的，且效果优于并行缩放。
    *   **计算任务（如MedCalc-Bench）**：**单一长链推理**（增加预算）效果最佳。

2.  **医学模型的领域特定瓶颈**：
    *   **医学模型与计算推理的脱节**：医学专用的LLM在医学问答任务上表现优异，但在**临床计算任务上**反而落后于通用模型。这表明现有医学微调侧重于**定性的临床知识**，而非**定量的程序性逻辑**。
    *   **多模态模型的视觉推理瓶颈**：大多数VLM无法有效利用扩展的Token预算进行视觉推理，表现提升远不如LLM。结构性的视觉-语言对齐问题是关键障碍，而非简单的计算量问题。

3.  **对“临床权威”的认知脆弱性**：
    *   模型在面对伪装成“专家医生”的误导性信息时，会**轻易放弃自己正确的推理路径**，即使是正确的答案。这种脆弱性在困难任务上更为显著。
    *   虽然测试时缩放（特别是针对模型定制的策略）能提升部分鲁棒性，但**无法**恢复至无干扰的基线水平。

4.  **最优策略是“模型-任务”感知的**：
    *   没有通用的最佳策略。例如，`HuatuoGPT-o1`（短推理模型）更适合混合缩放，而`m1`（长推理模型）则从简单增加预算中获益更多。
